## 1. 기능 요구사항 (Functional Requirements)

| ID | 구분 | 요구사항 | 우선순위 | 인수 기준 |
|----|------|----------|----------|-----------|
| REQ-001 | 회원 인증 | 이메일/비밀번호로 회원가입 및 로그인이 가능해야 한다 | Must | 이메일+비밀번호 입력 후 로그인 성공, JWT 발급 |
| REQ-002 | 회원 인증 | Google/Kakao 소셜 로그인이 가능해야 한다 | Must | 소셜 OAuth 인증 후 자동 계정 생성 및 로그인 |
| REQ-003 | 회원 인증 | 비밀번호 재설정 이메일을 발송할 수 있어야 한다 | Should | 이메일 입력 시 재설정 링크 발송, 링크 클릭 후 변경 가능 |
| REQ-004 | 그룹 관리 | 사용자는 그룹을 생성할 수 있어야 한다 | Must | 그룹명, 설명, 커버 이미지 설정 후 생성 성공 |
| REQ-005 | 그룹 관리 | 그룹 오너는 초대 링크로 멤버를 초대할 수 있어야 한다 | Must | 초대 링크 생성, 링크 접속 시 가입/수락 화면 표시 |
| REQ-006 | 그룹 관리 | 초대를 수락한 사용자만 그룹 캘린더에 접근할 수 있어야 한다 | Must | 초대 미수락 사용자는 그룹 접근 불가 |
| REQ-007 | 그룹 관리 | 오너는 멤버를 강퇴할 수 있어야 한다 | Should | 강퇴 후 해당 멤버의 그룹 접근이 즉시 차단됨 |
| REQ-008 | 그룹 관리 | 멤버는 그룹을 탈퇴할 수 있어야 한다 | Must | 탈퇴 확인 후 그룹 목록에서 제거 |
| REQ-009 | 공유 캘린더 | 그룹 구성원은 공유 캘린더를 월간/주간/일간 뷰로 조회할 수 있어야 한다 | Must | 세 가지 뷰 전환 정상 동작 |
| REQ-010 | 공유 캘린더 | 그룹 구성원은 캘린더에 일정을 등록할 수 있어야 한다 | Must | 제목, 날짜·시간, 색상 태그 입력 후 캘린더에 표시 |
| REQ-011 | 공유 캘린더 | 일정 등록자 및 오너는 일정을 수정·삭제할 수 있어야 한다 | Must | 권한 없는 사용자의 수정·삭제 요청 차단 |
| REQ-012 | 공유 캘린더 | 개인 일정과 그룹 일정을 분리하여 조회할 수 있어야 한다 | Should | 개인/그룹 레이어 전환 토글 동작 |
| REQ-013 | 다이어리 꾸미기 | 일정 상세에 텍스트 메모를 작성할 수 있어야 한다 | Must | 메모 저장 및 조회 가능 |
| REQ-014 | 다이어리 꾸미기 | 일정 상세에 사진을 복수 장 업로드하고 갤러리로 표시할 수 있어야 한다 | Must | 최대 10장, 10MB/장, 갤러리 UI 표시 |
| REQ-015 | 다이어리 꾸미기 | 일정 상세에 YouTube URL을 임베드할 수 있어야 한다 | Should | URL 입력 시 영상 플레이어 임베드 표시 |
| REQ-016 | 다이어리 꾸미기 | 일정 상세에 외부 URL을 OG 카드로 첨부할 수 있어야 한다 | Should | URL 입력 시 제목·설명·이미지가 카드로 표시 |
| REQ-017 | 다이어리 꾸미기 | 일정에 대표 이모지를 설정할 수 있어야 한다 | Must | 이모지 피커에서 선택, 캘린더 뷰에서 아이콘으로 표시 |
| REQ-018 | 다이어리 꾸미기 | 일정 상세에 장소를 검색하고 지도 핀으로 첨부할 수 있어야 한다 | Must | Kakao Map으로 장소 검색 후 핀 표시, 저장 |
| REQ-019 | 알림 | 새 일정 등록 시 그룹 구성원에게 앱 내 알림이 전송되어야 한다 | Must | 일정 등록 후 다른 멤버의 알림 목록에 표시 |
| REQ-020 | 알림 | 일정 수정·삭제 시 그룹 구성원에게 알림이 전송되어야 한다 | Should | 변경 내용과 함께 알림 표시 |
| REQ-021 | 알림 | 알림 읽음 처리 및 전체 알림 목록 조회가 가능해야 한다 | Must | 읽음 처리 후 UI 상태 변경, 전체 목록 조회 |

## 2. 비기능 요구사항 (Non-Functional Requirements)

| ID | 구분 | 요구사항 | 기준값 |
|----|------|----------|--------|
| NFR-001 | 성능 | 동시 접속자를 안정적으로 처리해야 한다 | 동시 접속 500명 |
| NFR-002 | 성능 | 일정 목록 로딩 시간이 기준 이하여야 한다 | 2초 이내 |
| NFR-003 | 성능 | 사진 업로드 응답 시간이 기준 이하여야 한다 | 5초 이내 (10MB 기준) |
| NFR-004 | 보안 | 회원 비밀번호는 암호화하여 저장해야 한다 | bcryptjs 해시 처리 |
| NFR-005 | 보안 | JWT 토큰은 만료 시간을 설정해야 한다 | Access: 1시간, Refresh: 7일 |
| NFR-006 | 보안 | 그룹 초대 링크는 만료 시간이 있어야 한다 | 72시간 후 만료 |
| NFR-007 | 보안 | 비인가 사용자의 API 접근을 차단해야 한다 | 401/403 응답 처리 |
| NFR-008 | 접근성 | 모바일 반응형 웹을 지원해야 한다 | 375px ~ 1920px 정상 표시 |
| NFR-009 | 접근성 | iOS/Android 기본 브라우저에서 정상 동작해야 한다 | Safari, Chrome 최신 버전 |
| NFR-010 | 미디어 | 사진 업로드 용량 제한을 적용해야 한다 | 최대 10MB/장, 10장/일정 |
| NFR-011 | 미디어 | 영상 직접 업로드 용량 제한을 적용해야 한다 | 최대 100MB/건 |
| NFR-012 | 확장성 | 그룹 수·멤버 수 증가에 수평 확장 가능해야 한다 | Supabase 기반 수평 확장 |
