## 2. 리서치 자료 목록

### 2-1. 국내 모바일 캘린더 앱 사용 현황

**출처**: 모바일인덱스 / 앱에이프
**발표일**: 2025-Q4
**자료 유형**: 통계

**요약**:
국내 캘린더 앱 월간 활성 사용자(MAU)는 꾸준히 증가 중이며, 구글 캘린더가 1위를 유지하고 있다. 그러나 MZ세대를 중심으로 '일정 공유'와 '추억 기록'을 동시에 충족하는 서비스에 대한 수요가 증가하고 있다. 소규모 그룹 전용 캘린더 앱(예: TimeTree)은 10~30대 여성 사용자를 중심으로 빠르게 성장하고 있다.

**주요 인사이트**:
- 구글 캘린더 MAU는 전체 1위이나 다이어리형 꾸미기 기능은 전무
- TimeTree는 그룹 캘린더에 특화되어 빠르게 성장 중
- 20~30대 여성 사용자에서 비주얼 꾸미기 기능 수요가 높음

**시장 데이터**:
- 국내 캘린더 앱 시장: 약 3,000억원 규모 추정
- 성장률: 연 12~15%
- 주요 플레이어: Google, Naver, TimeTree, Kakao

**프로젝트 적용 방안**:
그룹 캘린더 + 미디어 꾸미기 결합으로 기존 앱 대비 차별화. 20~30대 여성을 핵심 초기 타깃으로 설정.

**키워드**: `공유캘린더`, `그룹일정`, `MZ세대`

### 2-2. TimeTree 서비스 분석

**출처**: TimeTree 공식 사이트 / 앱스토어 리뷰
**발표일**: 2025
**자료 유형**: 케이스 스터디

**요약**:
TimeTree는 일본 발 그룹 캘린더 앱으로, 커플·가족·친구 그룹이 일정을 공유하고 댓글을 달 수 있는 기능을 제공한다. 국내에서도 상당한 사용자 기반을 보유하고 있으나, 미디어 첨부 기능은 사진 1장 수준에 그치며 영상·지도·URL 카드 등은 지원하지 않는다.

**주요 인사이트**:
- 그룹 캘린더 특화이지만 꾸미기 기능이 빈약
- 앱스토어 리뷰에서 "사진 여러 장 올리고 싶다", "지도 첨부가 필요하다" 등의 요청이 다수
- UI/UX가 다소 복잡하다는 지적 존재

**프로젝트 적용 방안**:
TimeTree의 그룹 캘린더 개념을 유지하되, 멀티미디어 꾸미기 기능으로 차별화.

**키워드**: `TimeTree`, `그룹캘린더`, `경쟁분석`

### 2-3. 비트윈(Between) 커플 앱 분석

**출처**: VCNC 공식 자료 / 앱스토어
**발표일**: 2025
**자료 유형**: 케이스 스터디

**요약**:
비트윈은 커플 전용 프라이빗 SNS로, 사진·다이어리·달력을 통합한 서비스를 제공한다. 커플 한정이라는 제약이 있지만, 다이어리형 기록에 대한 높은 만족도를 보인다. "두 사람만의 공간"이라는 프라이빗 컨셉이 핵심 경쟁력이다.

**주요 인사이트**:
- 프라이빗 + 다이어리형 기록은 사용자 만족도가 높음
- 커플 한정이라는 제약이 있어 친구 그룹·가족 시장은 공략 안 됨
- 사진 위주이며 영상·지도·URL 카드 기능은 없음

**프로젝트 적용 방안**:
비트윈의 프라이빗 다이어리 감성을 유지하되, 커플 외 친구 그룹·가족으로 타깃을 확장.

**키워드**: `Between`, `커플앱`, `다이어리`

### 2-4. 인스타그램 '친한 친구' 기능 트렌드

**출처**: Meta 발표 자료 / IT 뉴스
**발표일**: 2025
**자료 유형**: 블로그 포스트

**요약**:
인스타그램 '친한 친구' 기능과 BeReal 앱의 성공은 가까운 지인과의 소규모 프라이빗 공유에 대한 수요가 증가하고 있음을 보여준다. 대형 SNS 피로감으로 인해 소수의 지인과 일상을 공유하는 마이크로 SNS 트렌드가 강화되고 있다.

**주요 인사이트**:
- 대형 SNS 피로감 → 소규모 프라이빗 공유 트렌드 확산
- 일상 기록보다 '특별한 순간' 중심의 기록 선호
- 실시간 공유보다 '추억 아카이빙' 수요 증가

**프로젝트 적용 방안**:
소규모 그룹 초대 기반 프라이빗 서비스로 포지셔닝. 일정과 연결된 추억 기록 기능 강화.

**키워드**: `마이크로SNS`, `프라이빗`, `소규모공유`

### 2-5. 지도/위치 기반 기록 서비스 동향

**출처**: Google Maps, Kakao Map 개발자 문서
**발표일**: 2025
**자료 유형**: 기술 자료

**요약**:
구글 포토의 '추억' 기능, 카카오맵의 '내 장소' 기능 등 위치 기반 추억 기록 서비스가 확산되고 있다. 여행지, 맛집, 모임 장소를 지도와 연결해 기록하는 수요가 증가하고 있으며, 이를 일정과 연동하는 서비스는 아직 부재하다.

**주요 인사이트**:
- 장소 + 추억 기록 연동 서비스 수요 증가
- 일정과 지도를 연결하는 서비스는 경쟁 공백 존재
- Kakao Map API는 국내 특화, Google Maps는 글로벌 표준

**프로젝트 적용 방안**:
일정 상세에 Kakao Map API를 활용한 장소 검색 및 핀 표시 기능 구현. 지도 첨부를 핵심 차별화 요소로 활용.

**키워드**: `위치기반`, `지도연동`, `추억기록`

### 2-6. 모바일 퍼스트 앱 설계 트렌드

**출처**: Nielsen / App Annie 리포트
**발표일**: 2025
**자료 유형**: 보고서

**요약**:
모바일 앱 사용 시간이 전체 디지털 미디어의 70%를 초과했다. 특히 20~30대 MZ세대는 스마트폰 중심으로 일정 관리·기록·공유를 처리하며, 별도 앱 설치 없이 웹 브라우저로 네이티브급 경험을 원하는 PWA 트렌드가 부상하고 있다.

**주요 인사이트**:
- 모바일 퍼스트 설계가 필수
- PWA(Progressive Web App) 기반 서비스가 경쟁력
- 빠른 로딩과 오프라인 지원이 사용자 경험의 핵심

**프로젝트 적용 방안**:
Next.js + 반응형 설계로 모바일 웹에서 네이티브급 경험 제공. 1차 릴리즈는 모바일 웹 중심으로 진행.

**키워드**: `모바일퍼스트`, `PWA`, `반응형`

### 2-7. 사진·영상 공유 SNS 사용자 행동 분석

**출처**: DataReportal 2025 Global Digital Report
**발표일**: 2025
**자료 유형**: 보고서

**요약**:
사용자들은 평균 하루 10장 이상의 사진을 촬영하며, 이 중 30%만 SNS에 공유한다. 나머지는 '나만 보는' 개인 아카이브나 '가까운 지인 공유' 용도로 저장한다. 영상은 짧은 클립(1분 이내) 위주로 공유 수요가 높다.

**주요 인사이트**:
- 사진·영상 기록 욕구는 높지만, 공개 SNS 부담감으로 비공개 공유 선호
- 짧은 영상(1분 이내) 첨부 기능이 중요
- 다중 사진 업로드(갤러리)가 단일 사진보다 선호됨

**프로젝트 적용 방안**:
다중 사진 업로드 갤러리 + 영상 URL 임베드(YouTube/서버 업로드) 지원. 비공개 그룹 공유 강조.

**키워드**: `사진공유`, `영상클립`, `비공개공유`

### 2-8. 국내 소모임·동호회 디지털 서비스 니즈

**출처**: 소모임 앱 사용자 인터뷰 / 커뮤니티 리서치
**발표일**: 2025
**자료 유형**: 케이스 스터디

**요약**:
국내 소모임·동호회 운영자들은 일정 공유를 위해 카카오톡 단톡방에 의존하고 있으나, 일정 관리·참석 확인·장소 공유가 분산되어 불편함을 호소한다. 통합된 소모임 일정 관리 도구에 대한 수요가 높다.

**주요 인사이트**:
- 카카오톡은 일정 공유에 부적합 (정보가 메시지에 묻힘)
- 장소 공유, 참석 여부 확인, 일정 알림이 핵심 니즈
- 모임 사진 아카이빙 기능도 수요 높음

**프로젝트 적용 방안**:
그룹 캘린더 + 장소 첨부 + 알림 기능으로 소모임 총무·운영자를 핵심 유저로 공략.

**키워드**: `소모임`, `동호회`, `일정관리`

### 2-9. 이모지·스티커 기반 다이어리 앱 트렌드

**출처**: LINE 공식 블로그 / Apple 앱스토어 트렌드
**발표일**: 2025
**자료 유형**: 블로그 포스트

**요약**:
이모지와 스티커를 활용한 다이어리 앱이 10~20대 중심으로 큰 인기를 끌고 있다. Notion, 네이버 캘린더의 이모지 일정 지원, 애플 캘린더의 이모지 지원이 사용자 호응을 얻고 있다. 이모지는 감정 표현과 일정 구분을 동시에 가능케 하는 직관적인 UI 요소다.

**주요 인사이트**:
- 이모지 + 일정 = 시각적 캘린더로 한눈에 파악 가능
- 10~20대 타깃에서 이모지 활용도 매우 높음
- 이모지 피커 UI는 모바일에서 필수 컴포넌트

**프로젝트 적용 방안**:
일정 대표 이모지 설정 기능 구현. 캘린더 뷰에서 이모지가 일정 아이콘 역할을 하도록 설계.

**키워드**: `이모지`, `스티커`, `비주얼다이어리`

### 2-10. URL 미리보기(OG 카드) 콘텐츠 공유 트렌드

**출처**: Twitter/X, Kakao Talk 링크 공유 분석
**발표일**: 2025
**자료 유형**: 기술 자료

**요약**:
URL을 공유할 때 OpenGraph(OG) 태그를 파싱하여 제목·설명·이미지를 카드로 미리보기하는 기능이 메신저·SNS에서 표준으로 자리잡았다. 레스토랑 예약 링크, 여행 블로그, 공연 예매 링크 등을 일정에 첨부하는 수요가 높다.

**주요 인사이트**:
- URL 카드 미리보기는 사용자 편의성을 크게 향상
- 여행·외식·문화 관련 URL 첨부가 주요 활용 케이스
- OG 태그 미지원 사이트에 대한 fallback 처리 필요

**프로젝트 적용 방안**:
일정 상세에 URL 입력 시 OG 태그 파싱하여 카드 미리보기 자동 생성. Fallback은 URL 텍스트 링크로 처리.

**키워드**: `URL카드`, `OG태그`, `링크공유`

## 3. 시장 분석 요약

### 3.1 시장 현황

| 항목 | 내용 | 출처 |
|------|------|------|
| 국내 캘린더 앱 시장 규모 | 약 3,000억원 | 자료 2-1 |
| 성장률 | 연 12~15% | 자료 2-1 |
| 타깃 세그먼트 규모 | 20~35세, 국내 약 1,200만명 | 인구통계 |
| 시장 성숙도 | 성장기 (그룹 캘린더 세그먼트) | 자료 2-1, 2-2 |

### 3.2 주요 트렌드

1. **비주얼 다이어리화**: 텍스트 중심 → 사진·이모지·지도 중심 기록 전환
2. **소규모 프라이빗 공유**: 대형 SNS 피로감 → 친한 지인 소규모 그룹 선호
3. **위치 기반 추억 기록**: 장소와 연결된 일정·추억 아카이빙 수요 증가
4. **모바일 퍼스트**: 스마트폰 중심 일정 관리, PWA 트렌드 부상

### 3.3 경쟁 환경

| 경쟁사/서비스 | 핵심 기능 | 강점 | 약점 | 가격 모델 | 사용자 규모 |
|---------------|-----------|------|------|-----------|-------------|
| 구글 캘린더 | 일정 공유, 알림 | 생태계, 안정성 | 꾸미기 기능 없음 | 무료 | 전 세계 1위 |
| TimeTree | 그룹 캘린더, 댓글 | 그룹 특화 | 미디어 빈약 (사진 1장) | 무료/프리미엄 | 국내 수백만 |
| 비트윈 | 커플 다이어리 | 감성 UI, 다이어리 | 커플만 가능 | 무료/프리미엄 | 국내 수백만 |
| 네이버 캘린더 | 일정 공유 | 국내 생태계 | 꾸미기 없음 | 무료 | 국내 수천만 |
| **Share Diary** | **그룹 캘린더+다이어리** | **멀티미디어 꾸미기+지도** | **신규 서비스** | **무료 (프리미엄 예정)** | **진입 예정** |

### 3.4 기술 동향

| 기술 | 성숙도 | 적용 가능성 | 설명 |
|------|--------|-------------|------|
| Next.js App Router | 높음 | 높음 | SSR/SSG + API Routes 통합, Vercel 최적화 |
| Supabase Realtime | 중간 | 높음 | WebSocket 기반 실시간 알림 |
| Kakao Map API | 높음 | 높음 | 국내 위치 검색, 지도 핀 표시 |
| OG 태그 파싱 | 높음 | 중간 | URL 카드 미리보기 (CORS 우회 처리 필요) |

| 사용자 유형 | 핵심 니즈 | 현재 해결 방식 | 불만 사항 |
|-------------|-----------|----------------|-----------|
| 친구 그룹 | 여행·모임 일정 공유 + 사진 기록 | 카카오톡 + 구글 캘린더 따로 | 두 앱을 오가야 함 |
| 커플 | 기념일·데이트 다이어리 기록 | Between 또는 인스타 비공개 | 일정 연동이 안 됨 |
| 소모임 총무 | 정기 모임 일정 공지 + 장소 공유 | 카카오톡 단톡방 | 정보가 메시지에 묻힘 |

## 4. 프로젝트 시사점

### 4.1 기회 요인

1. **경쟁 공백**: 그룹 캘린더 + 멀티미디어 꾸미기를 동시에 제공하는 서비스가 국내에 없음 (자료 2-2, 2-3)
2. **상승 트렌드**: 프라이빗 소규모 공유, 비주얼 다이어리 수요 빠르게 증가 (자료 2-4, 2-9)
3. **위치 기반 차별화**: 일정 + 지도 연동 서비스 공백 (자료 2-5)

### 4.2 위험 요소

| 위험 요소 | 영향도 | 대응 방안 |
|-----------|--------|-----------|
| TimeTree의 꾸미기 기능 강화 | High | 빠른 출시 + 지도·URL 카드 선점 |
| 카카오 캘린더의 그룹 기능 강화 | Medium | 다이어리 감성·UX로 차별화 |
| 미디어 저장 비용 증가 | Medium | Supabase Storage 정책 + 용량 제한 |

### 4.3 차별화 기회

1. **멀티미디어 올인원**: 텍스트 + 사진(갤러리) + 영상 + URL 카드 + 이모지 + 지도를 하나의 일정에
2. **다이어리 감성 UI**: 캘린더보다 다이어리에 가까운 일정 상세 화면
3. **초대 기반 프라이빗**: 링크 초대 → 수락 → 그룹 전용 공간으로 신뢰감 높은 공유 환경
