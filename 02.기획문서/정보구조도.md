## 1. 전체 사이트맵

```mermaid
flowchart TD
    A([서비스 진입]) --> B{로그인 여부}
    B -->|비로그인| C[로그인/회원가입]
    B -->|로그인| D[홈 - 캘린더]

    C --> C1[이메일 로그인]
    C --> C2[소셜 로그인]
    C --> C3[회원가입]
    C --> C4[비밀번호 재설정]

    D --> D1[월간 캘린더 뷰]
    D --> D2[주간 캘린더 뷰]
    D --> D3[일간 캘린더 뷰]

    D --> E[그룹 관리]
    E --> E1[내 그룹 목록]
    E --> E2[그룹 생성]
    E --> E3[그룹 상세/설정]
    E3 --> E4[멤버 관리]
    E3 --> E5[초대 링크 생성]

    D --> F[일정 관리]
    F --> F1[일정 등록]
    F --> F2[일정 상세]
    F2 --> F3[다이어리 꾸미기]
    F3 --> F31[텍스트 메모]

    F3 --> F33[이모지 설정]

    D --> G[알림]

    D --> H[내 설정]

    H --> H2[알림 설정]
    H --> H3[로그아웃]
```

## 2. 사용자 흐름 (User Flow)

### 2.1 신규 사용자 가입 흐름

```mermaid
flowchart LR
    Start([앱 접속]) --> Login[로그인 화면]
    Login --> SignupLink[회원가입 클릭]
    SignupLink --> Signup[이메일/비밀번호 입력]
    Signup --> Verify{이메일 인증}
    Verify -->|성공| Home[홈 캘린더]
    Verify -->|실패| Signup
    Login --> Social[소셜 로그인]
    Social --> SocialAuth[OAuth 인증]
    SocialAuth --> Home
```

---

### 2.2 그룹 생성 및 초대 흐름

```mermaid
flowchart LR
    Home[홈 캘린더] --> GroupList[그룹 목록]
    GroupList --> CreateGroup[그룹 생성]
    CreateGroup --> SetName[그룹명/설명/이미지 설정]
    SetName --> GroupCreated[그룹 생성 완료]
    GroupCreated --> InviteLink[초대 링크 생성]
    InviteLink --> Share[링크 공유]
    Share --> FriendAccess[친구가 링크 접속]
    FriendAccess --> FriendJoin{로그인 여부}
    FriendJoin -->|비로그인| FriendLogin[로그인/가입]
    FriendLogin --> AcceptInvite[초대 수락]
    FriendJoin -->|로그인| AcceptInvite
    AcceptInvite --> SharedCalendar[공유 캘린더 접근]
```

---

### 2.3 일정 등록 및 다이어리 꾸미기 흐름

```mermaid
flowchart LR
    Calendar[캘린더 뷰] --> SelectDate[날짜 선택]
    SelectDate --> AddSchedule[일정 등록 화면]
    AddSchedule --> InputTitle[제목 입력]
    InputTitle --> SetDateTime[날짜/시간 설정]
    SetDateTime --> SetEmoji[이모지 선택 - 선택]
    SetEmoji --> SetColor[색상 태그 선택 - 선택]
    SetColor --> Save[일정 저장]
    Save --> ScheduleDetail[일정 상세 화면]
    ScheduleDetail --> AddMedia{콘텐츠 추가}
    AddMedia --> Text[텍스트 메모]
    AddMedia --> Photo[사진 업로드]
    AddMedia --> Map[지도/위치 첨부]
    AddMedia --> URL[URL 카드 추가]
    AddMedia --> Video[영상 첨부]
    Text --> Notify[그룹 멤버에게 알림 발송]
    Photo --> Notify
    Map --> Notify
    URL --> Notify
    Video --> Notify
```

---

### 2.4 알림 수신 및 확인 흐름

```mermaid
flowchart LR
    Event[일정 등록/수정/삭제] --> System[서버 알림 생성]
    System --> Push[Supabase Realtime push]
    Push --> Badge[알림 뱃지 업데이트]
    Badge --> Bell[알림 아이콘 클릭]
    Bell --> NotifList[알림 목록 조회]
    NotifList --> SelectNotif[알림 선택]
    SelectNotif --> ScheduleDetail[해당 일정 상세 이동]
    NotifList --> MarkRead[읽음 처리]
```

## 3. 화면-기능 매핑

| 화면명 | URL | 주요 기능 | 관련 기능 ID |
|--------|-----|-----------|-------------|
| 로그인 | /login | 이메일/소셜 로그인 | F-001 |
| 회원가입 | /signup | 이메일 회원가입 | F-001 |
| 홈 캘린더 | / | 공유 캘린더 조회 (월간) | F-003 |
| 그룹 목록 | /groups | 내 그룹 목록 | F-002 |
| 그룹 생성 | /groups/new | 그룹 생성 | F-002 |
| 그룹 설정 | /groups/:id/settings | 멤버 관리, 초대 링크 | F-002 |
| 초대 수락 | /invite/:token | 초대 링크 수락 | F-002 |
| 일정 등록 | /schedules/new | 일정 생성 | F-004, F-007 |
| 일정 상세 | /schedules/:id | 일정 조회 + 다이어리 꾸미기 | F-004~F-010 |
| 알림 | /notifications | 알림 목록, 읽음 처리 | F-011 |
| 설정 | /settings | 프로필, 알림 설정 | F-001 |
