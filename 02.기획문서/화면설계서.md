### 3.2 S-COMMON-ONBOARDING — 온보딩 (3 step)

| 항목 | 내용 |
|------|------|

| 관련 기능 | F-001, F-004, F-101, F-103, F-701 |

**3단계 구조**

```
Step 1: 닉네임 입력
┌─────────────────────────┐
│  반가워요! 👋            │  ← H1
│  뭐라고 부를까요?        │
│                         │
│  ┌───────────────────┐  │
│  │ 닉네임 (2~20자)   │  │  ← Input
│  └───────────────────┘  │
│  ⓘ 그룹원에게 표시돼요   │
│                         │
│  [다음 →]                │  ← primary, disabled until 2자
└─────────────────────────┘

Step 2: 첫 그룹 시작
┌─────────────────────────┐
│  우리만의 캘린더를       │  ← H1
│  시작해볼까요?           │
│                         │
│  ┌─────────────────┐    │
│  │ + 새 그룹 만들기 │   │  ← Card (primary)
│  └─────────────────┘    │
│  ┌─────────────────┐    │
│  │ 🔗 초대 코드 입력│   │  ← Card (secondary)
│  └─────────────────┘    │
│                         │
│  [건너뛰기]              │  ← ghost, 작게
└─────────────────────────┘

Step 3: PWA + 푸시 안내
┌─────────────────────────┐
│  📱 홈 화면에 추가하면   │
│  앱처럼 사용할 수 있어요 │
│                         │
│  [📱 설치하기]           │  ← primary
│  [🔔 알림 받기]          │  ← primary
│                         │
│  [나중에 →]              │  ← ghost
└─────────────────────────┘
```

**검증**: 닉네임 2~20자, 코드 6자리 영숫자.
