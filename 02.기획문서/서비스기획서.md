## 1. Executive Summary

### 1.1 한 줄 요약

> **"우리만의 캘린더를 함께 꾸미고, 일정 너머의 추억까지 간직하는 그룹형 다이어리"**
>
> 친구·연인·가족 등 5명 미만 친밀 그룹이 하나의 캘린더를 공유하며, 지도·사진·영상·이모지·스티커로 일정을 꾸미고 아카이빙할 수 있는 **폐쇄형 감성 공유 캘린더 서비스**입니다.

### 1.2 핵심 지표

| 항목 | 내용 |
|------|------|
| 서비스명 | 온라인 다이어리 꾸미기 (Shared Diary Calendar) |
| 목표 시장 | 글로벌 디지털 캘린더 시장 (28억~50억 달러, 2025년) / 국내 Z세대 감성 다꾸 시장 (약 500억 원) |
| 타겟 사용자 | Z세대 절친 그룹, 2030 커플, 가족, 소규모 동호회 (그룹당 평균 3.2명) |
| 핵심 가치 | **일정(Schedule) + 꾸미기(Deco) + 폐쇄형 공유(Closed Social)** 의 결합 |
| 수익 모델 | Freemium 구독 (Pro) + 스티커 마켓 거버넌스 수수료 (W5+ 고도화) |
| 목표 기간 | 16주 (4개월, W1~W16) — MVP 런칭 W12 목표 |
| 핵심 KPI | 일정 조회 응답 1초 이내, 그룹 주간 재방문율 80% 이상, 가용성 99.5% |

## 2. 서비스 배경 및 시장 기회

### 2.1 시장 현황

| 항목 | 수치 | 출처 |
|------|------|------|
| 글로벌 디지털 캘린더 시장 규모 | 28억 ~ 50억 달러 (2025년) | 마켓리서치 #2-10 (DataIntelo / Datahorizzon) |
| 글로벌 시장 CAGR | 8% ~ 12% (2025~2033) | 마켓리서치 #2-10 |
| 국내 Z세대 감성 다꾸 앱 시장 | 약 500억 원 (2025 추산) | 마켓리서치 §3.1 (한국콘텐츠진흥원) |
| 폐쇄형 소셜/감성 기록 앱 성장률 | 연 12.5% | 마켓리서치 §3.1 (AppAnnie) |
| Z세대 다꾸 인구 비중 | 약 73% | 마켓리서치 #2-1 (대학내일20대연구소) |
| 공유 캘린더 사용자 평균 그룹 크기 | 3.2명 | 마켓리서치 #2-2 (오픈서베이) |

### 2.2 시장 기회

- **기회 1 — 감성 아카이빙 공백**: 글로벌 1위 TimeTree(7,000만 유저, 누적 일정 140억 건)조차 AI 일정 관리에 치중하여 "지난 일정 아카이빙" 영역은 비어 있습니다. 사용자의 61%가 아카이빙 부실에, 48%가 텍스트 위주 시각 요소에 불만을 표명합니다. — 근거: 마켓리서치 #2-2
- **기회 2 — '토핑경제'의 웹 이식 가능성**: Z세대의 85%가 일상 소품을 개인화하는 '토핑경제·별다꾸' 문화를 가지고 있으며, 다이어리는 가장 대표적인 꾸미기 매체입니다. 캘린더 일정 자체를 캔버스로 제공하면 강력한 락인 효과를 만들 수 있습니다. — 근거: 마켓리서치 #2-1, #2-4
- **기회 3 — 폐쇄형 소셜로의 회귀 트렌드**: 개방형 SNS 피로감으로 5명 미만 폐쇄형 버티컬 SNS의 리텐션이 대형 SNS 대비 1.5배 높고, 이용 시간은 연 18% 증가하고 있습니다. — 근거: 마켓리서치 #2-3, #2-5

### 2.3 경쟁 환경

| 경쟁사 | 강점 | 약점 | 시장 점유 / 사용자 규모 |
|--------|------|------|-------------------------|
| **TimeTree** | 캘린더 공유 안정성, AI 일정 관리, 글로벌 인지도 | 일정 꾸미기 부재, 광고 노출 多, 감성 아카이빙 공백 | 글로벌 7,000만 유저 / 일정 140억 건+ |
| **Between** | 1:1 커플 완전 폐쇄성, 강력한 커플 감성 UI | 다수 그룹 불가, 일정별 데코 기능 부족 | 누적 다운로드 3,500만 건+ |
| **Notion** | 자유 템플릿 레이아웃, 데이터베이스 기능 | 모바일 UX 무거움, 실시간 리액션 부재, 학습곡선 가파름 | 글로벌 1억 유저 (해외 80%) |
| **todomate** | 깔끔한 위젯, 친구 간 이모지 리액션 | 일정/지도/멀티미디어 아카이빙 한계 | 누적 사용자 300만 명+ |
| **우리 서비스** | **일정 캔버스 에디터 + 지도 데코 + 폐쇄형 그룹 + 마이크로 리액션** 의 유일한 결합 | 신규 진입 (브랜드 인지도 0) | 진입 예정 (Niche 우위 노림) |

> 경쟁사 어느 곳도 "일정 꾸미기 + 소규모 폐쇄 공유 + 아카이빙"의 세 요소를 동시에 만족시키지 못함. 이 교집합이 우리의 **블루오션 포지셔닝**입니다.

## 4. 서비스 전략

### 4.1 핵심 가치 제안 (Value Proposition)

> **"우리만 보는 캘린더에, 우리만의 추억을 토핑한다."**
>
> 일정은 기록의 시작점이고, 꾸미기는 감정의 표현이며, 폐쇄형 그룹은 안전한 무대입니다. 이 세 가지를 동시에 만족시키는 유일한 서비스를 지향합니다.

세 가지 핵심 약속:
1. **자유로운 캔버스**: 일정 하나가 작은 도화지 — 지도, 사진, 영상, 스티커, 이모지로 자유 배치
2. **친밀한 객석**: 초대 코드로 들어온 우리 그룹만의 폐쇄 공간 — 부담 없이 마이크로 리액션
3. **사라지지 않는 추억**: 단톡방·인스타와 달리 시간순으로 영구 보존되는 우리만의 히스토리 북

### 4.2 서비스 범위 (착수보고서 기준 정합)

| 구분 | 항목 | 우선순위 | 설명 |
|------|------|----------|------|
| MVP (In Scope) | 그룹 공유 캘린더 | P0 | 초대 링크/코드 기반 멤버 가입, 그룹별 공동 일정 등록·조회·수정 |
| MVP (In Scope) | 일정 꾸미기 에디터 | P0 | 지도 핀, 사진, 텍스트, URL 카드, 영상 임베드, 이모지 스티커 드래그앤드롭 |
| MVP (In Scope) | 다중 뷰 캘린더 | P0 | 월/주/일/리스트 뷰, 그룹별 색상, 멤버 필터 |
| MVP (In Scope) | 알림·리마인더 | P0 | 일정 등록·수정·D-day 웹 푸시·이메일 |
| MVP (In Scope) | 댓글·이모지 리액션 | P0 | 일정 카드 댓글, 6종 이모지 마이크로 리액션 |
| MVP (In Scope) | PWA·다크모드·HTTPS | P0 | 모바일 반응형 + 홈화면 추가 + 다크모드, 전 구간 HTTPS |
| 확장 (Phase 2) | 사용자 스티커 마켓 | P1 | 유저 제작 스티커 팩 거래 (W5 이후 고도화) |
| 확장 (Phase 2) | 외부 캘린더 연동 | P1 | Google Calendar, Apple iCal 동기화 |
| 확장 (Phase 3) | 유료 이모지/PG 결제 | P2 | 토스페이먼츠 연동, 마켓 거버넌스 |
| 확장 (Phase 3) | 1,000명 이상 스케일아웃 | P2 | M5 단계 Express 백엔드 분리 검토 |

**Out of Scope (착수보고서 §3.2 준수)**:
- 외부 캘린더(Google/Apple) 연동은 차기 고도화
- 유료 아이템 스토어/PG 결제는 1단계 제외
- 동시 접속 1,000명 이상 대규모 스케일아웃은 W5 후 검토

### 4.3 차별화 전략

1. **캔버스형 일정 에디터**: 경쟁사가 모두 "텍스트 + 위치 한 줄"의 정적 카드인 반면, 우리는 일정 클릭 시 도화지가 열려 자유 배치가 가능합니다. (참조: 마켓리서치 #2-1, #2-4)
2. **지도 기반 추억 매핑**: Kakao Map / Google Maps API를 통해 다녀온 장소들이 자동으로 지도 위 핀으로 누적, 데이트 코스 / 여행 동선이 시각화됩니다. (참조: 마켓리서치 #2-7)
3. **마이크로 리액션 루프**: todomate의 성공 공식(원클릭 이모지 피드백)을 캘린더형으로 확장. 6종 이모지로 매일 가벼운 상호작용 유도. (참조: 마켓리서치 #2-6)
4. **폐쇄형 안전 무대**: KISA 가이드라인 준수 암호화 + 초대 링크 일회성 만료 + RLS 기반 그룹 외 접근 차단. (참조: 마켓리서치 #2-9)
5. **앱 설치 0 마찰**: PWA로 앱마켓 우회, 홈화면 추가만으로 푸시·바로가기. 빌드 비용 70%↓ / 리텐션 40%↑ 사례 적용. (참조: 마켓리서치 #2-8)

## 7. 개발 전략

### 7.1 기술 스택 요약

> V0.42 표준 스택 기본값 — `Next.js + Tailwind CSS / Express.js / PostgreSQL / Vercel`
> **현재 단계: M1~M4 (API Routes 통합)** — `src/frontend/app/api/*`에 API 작성, `src/backend/`는 비활성화.

| 영역 | 기술 | 선정 사유 |
|------|------|-----------|
| 프론트엔드 | **Next.js 14 (App Router) + Tailwind CSS** | SSR/SSG 동시 지원, PWA 친화, Tailwind로 다꾸 UI 빠른 시제품화 |
| 백엔드 (M1~M4) | **Next.js Route Handlers** (`src/frontend/app/api/*`) | Vercel 통합 배포, 1인/소규모 운영 부하 최소화, M5에서 Express로 점진 이전 가능 |
| 데이터베이스 | **PostgreSQL (Supabase 호스팅)** | 관계형 + RLS 보안, Storage·Auth·Realtime 통합 |
| 스토리지 | **Supabase Storage** | 이미지/영상 CDN 자동화, RLS로 그룹 외 접근 차단 |
| 인증 | **Supabase Auth (소셜 로그인: Kakao, Google, Apple)** | Z세대 마찰 최소화 |
| 실시간 동기화 | **Supabase Realtime (Postgres LISTEN)** | 그룹원 일정 등록 즉시 캘린더 리렌더링 |
| 지도 | **Kakao Map + Google Maps API** | 국내(카카오) + 해외(구글) 듀얼 지원 |
| 영상 임베드 | **YouTube / Vimeo oEmbed** | 별도 인코딩 불요, URL만으로 영상 카드 |
| 결제 (Phase 3) | **토스페이먼츠** | 한국 사업자 PG 1순위, 멱등성 처리 명확 |
| 배포 | **Vercel** | GitHub 자동 배포, Edge 글로벌 CDN, Lambda 60초 한도 내 처리 |
| CI/CD | **GitHub Actions** | `tsc --noEmit` + Jest 자동화, 배포 직전 게이트 |
| 알림·자동화 | **n8n (WF 01~05)** | 슬랙·GitHub 연동, PM Agent |
