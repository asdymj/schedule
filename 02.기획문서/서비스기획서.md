# 서비스 기획서 (Service Plan)

**프로젝트명**: 온라인 다이어리 꾸미기 (Share Diary Calendar)
**작성일**: 2026-05-24
**버전**: v1.0

---

## 1. Executive Summary

### 1.1 한 줄 요약

친구 그룹과 함께 일정을 공유하고, 사진·지도·이모지로 다이어리처럼 꾸며 기록하는 프라이빗 공유 캘린더 서비스

### 1.2 핵심 지표

| 항목 | 내용 |
|------|------|
| 서비스명 | Share Diary (온라인 다이어리 꾸미기) |
| 목표 시장 | 국내 소규모 그룹 공유 캘린더 시장 |
| 타깃 사용자 | 20~35세, 친구 그룹·커플·소모임 구성원 (2~20명) |
| 핵심 가치 | 그룹 일정 공유 + 다이어리형 미디어 기록을 하나의 서비스에서 |
| 수익 모델 | 프리미엄 구독 (저장 용량 확장, 그룹 멤버 수 확대) |
| 목표 기간 | 2026-05-24 ~ 2026-06-28 (5주, MVP) |

## 2. 서비스 배경 및 시장 기회

### 2.1 시장 현황

| 항목 | 수치 | 출처 |
|------|------|------|
| 국내 캘린더 앱 시장 규모 | 약 3,000억원 | 마켓리서치 #1 |
| 연간 성장률 | 12~15% | 마켓리서치 #1 |
| 타깃 사용자 규모 (20~35세) | 약 1,200만명 | 통계청 |

### 2.2 시장 기회

- **기회 1**: 그룹 캘린더 + 멀티미디어 꾸미기 통합 서비스 공백 — 근거: 마켓리서치 #2, #3
- **기회 2**: 소규모 프라이빗 공유 수요 급증 (대형 SNS 피로감) — 근거: 마켓리서치 #4
- **기회 3**: 일정 + 지도 연동 서비스 공백 — 근거: 마켓리서치 #5

### 2.3 경쟁 환경

| 경쟁사 | 강점 | 약점 | 시장 점유율 |
|--------|------|------|-------------|
| 구글 캘린더 | 생태계 통합, 안정성 | 꾸미기 기능 없음 | 1위 |
| TimeTree | 그룹 캘린더 특화 | 미디어 첨부 빈약 | 성장 중 |
| 비트윈 | 커플 다이어리 감성 | 커플 전용, 그룹 불가 | 중간 |
| **Share Diary** | **그룹 캘린더 + 다이어리 꾸미기** | **신규 서비스** | **진입 예정** |

## 3. 타깃 사용자 정의

### 3.1 사용자 페르소나

**페르소나 1: 지은 (23세, 대학생)**

| 항목 | 내용 |
|------|------|
| 연령/직업 | 23세 대학생 |
| 핵심 니즈 | 친구들과 여행·MT 일정 공유 + 사진·위치 기록 |
| 현재 해결 방식 | 카카오톡 + 구글 캘린더를 따로 사용 |
| 불만 사항 | 두 앱을 오가야 하고, 사진이 카톡 대화방에 묻혀버림 |
| 기대 가치 | 일정과 사진·지도를 한 곳에서 다이어리처럼 기록하고 싶음 |

**페르소나 2: 민준 (30세, 직장인 소모임 총무)**

| 항목 | 내용 |
|------|------|
| 연령/직업 | 30세 직장인, 등산 동호회 총무 |
| 핵심 니즈 | 정기 모임 일정 공지 + 집합 장소(지도) + 참석 안내 |
| 현재 해결 방식 | 카카오톡 단톡방에 일정 공지 |
| 불만 사항 | 일정 정보가 메시지에 묻히고, 지각자가 장소를 못 찾음 |
| 기대 가치 | 모임 일정·장소·사진을 한 곳에서 관리하고 싶음 |

**페르소나 3: 수아 (27세, 커플)**

| 항목 | 내용 |
|------|------|
| 연령/직업 | 27세 직장인, 남자친구와 교제 중 |
| 핵심 니즈 | 기념일·데이트 장소를 사진과 이모지로 예쁘게 기록 |
| 현재 해결 방식 | 인스타그램 비공개 + Between 따로 사용 |
| 불만 사항 | Between은 커플 전용이라 친구 초대 불가 |
| 기대 가치 | 커플 + 친구 그룹 모두에서 쓸 수 있는 다이어리 앱 원함 |

### 3.2 사용자 세그먼트

| 세그먼트 | 비중 | 특성 | 우선순위 |
|----------|------|------|----------|
| 친구 그룹 (여행·모임) | 45% | 20~28세, 주로 여성, 사진·이모지 선호 | P0 |
| 커플 | 30% | 20~35세, 기념일 기록, 감성 UI 선호 | P0 |
| 소모임·동호회 | 25% | 25~40세, 총무 역할, 장소·알림 기능 중시 | P1 |

## 4. 서비스 전략

### 4.1 핵심 가치 제안 (Value Proposition)

"친구 그룹과 일정을 함께 만들고, 사진·지도·이모지로 다이어리처럼 꾸며 공유하는 프라이빗 캘린더"

### 4.2 서비스 범위

| 구분 | 항목 | 우선순위 | 설명 |
|------|------|----------|------|
| MVP | 회원 인증 (이메일/소셜) | P0 | 기본 가입·로그인 |
| MVP | 그룹 생성 및 초대 | P0 | 링크 초대, 멤버 관리 |
| MVP | 공유 캘린더 (CRUD) | P0 | 월간/주간 뷰, 일정 등록·수정·삭제 |
| MVP | 다이어리 꾸미기 | P0 | 텍스트, 사진, 이모지, 지도, URL 카드 |
| MVP | 앱 내 알림 | P0 | 새 일정 등록 시 그룹 알림 |
| 확장 | 영상 업로드 | P1 | 영상 파일 직접 업로드 |
| 확장 | 개인 일정 레이어 | P1 | 개인 일정과 그룹 일정 분리 뷰 |
| 확장 | 이메일/카카오 알림 | P2 | 외부 채널 알림 연동 |

### 4.3 차별화 전략

1. **멀티미디어 올인원**: 텍스트·사진·영상·URL·이모지·지도를 하나의 일정에 통합
2. **프라이빗 초대 기반**: 초대 수락 멤버만 접근 가능한 안전한 공유 환경
3. **다이어리 감성 UI**: 캘린더보다 다이어리에 가까운 감성적 일정 상세 화면

## 7. 개발 전략

### 7.1 기술 스택 요약

| 영역 | 기술 | 선정 사유 |
|------|------|-----------|
| 프론트엔드 | Next.js + Tailwind CSS | SSR/SSG, Vercel 최적화, 빠른 UI 구축 |
| 백엔드 | Next.js API Routes (M1~M4) | 단일 배포, CORS 불필요, 서버리스 |
| 데이터베이스 | PostgreSQL (Supabase) | 안정성, Supabase Auth/Storage 통합 |
| 인프라 | Vercel | 프론트+API 통합 배포, GitHub 연동 |
| 지도 | Kakao Map API | 국내 특화, 장소 검색·핀 표시 |

### 7.2 개발 일정 (마일스톤)

| Phase | 기간 | 목표 | 핵심 산출물 |
|-------|------|------|-------------|
| Phase 0: 기획 | W2~W3 | 요구사항 정의 완료 | 기능명세서, 화면설계서 |
| Phase 1: MVP | W4 | 핵심 기능 구현 | 프론트엔드 코드, API, DB |
| Phase 2: 검수 | W5 | 테스트 및 배포 | 테스트결과, CI/CD |
