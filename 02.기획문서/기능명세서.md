## 기능 상세

### F-001. 회원 인증 (이메일/소셜)

| 항목 | 내용 |
|------|------|
| 설명 | 이메일+비밀번호 또는 Google/Kakao 소셜 계정으로 회원가입 및 로그인 |
| 입력 | 이메일, 비밀번호 (이메일 로그인) / OAuth 인증 코드 (소셜) |
| 처리 | Supabase Auth를 통한 인증 처리, JWT Access/Refresh 토큰 발급 |
| 출력 | JWT Access Token (1시간), Refresh Token (7일), 사용자 정보 |
| 예외 처리 | 이메일 중복 → 409, 잘못된 비밀번호 → 401, 소셜 인증 실패 → 400 |
| 관련 화면 | SCR-001 (로그인), SCR-002 (회원가입) |
| 관련 API | API-001 (POST /auth/signup), API-002 (POST /auth/login), API-003 (POST /auth/social) |

### F-002. 그룹 생성 및 관리

| 항목 | 내용 |
|------|------|
| 설명 | 그룹 생성, 초대 링크 발급, 멤버 수락/강퇴/탈퇴, 오너/멤버 역할 관리 |
| 입력 | 그룹명 (최대 30자), 설명 (최대 100자), 커버 이미지 (선택) |
| 처리 | 그룹 생성 시 오너 자동 지정. 초대 링크는 UUID 기반 토큰, 72시간 만료. 초대 수락 시 group_members 테이블에 INSERT |
| 출력 | 생성된 그룹 정보, 초대 링크 URL |
| 예외 처리 | 만료된 초대 링크 → 410, 이미 가입된 그룹 → 409, 오너가 아닌 사용자의 강퇴 시도 → 403 |
| 관련 화면 | SCR-004 (그룹 목록), SCR-005 (그룹 생성), SCR-006 (그룹 설정) |
| 관련 API | API-010 (POST /groups), API-011 (POST /groups/:id/invite), API-012 (POST /groups/join/:token), API-013 (DELETE /groups/:id/members/:userId) |

### F-003. 공유 캘린더 조회

| 항목 | 내용 |
|------|------|
| 설명 | 그룹 공유 캘린더를 월간/주간/일간 뷰로 조회. 개인/그룹 일정 레이어 분리 |
| 입력 | 그룹 ID, 조회 기간 (년/월 또는 주), 뷰 타입 (monthly/weekly/daily) |
| 처리 | 해당 그룹의 schedules 테이블에서 기간 내 일정 조회. 개인/그룹 필터 적용 |
| 출력 | 일정 목록 (날짜, 제목, 이모지, 색상 태그) |
| 예외 처리 | 그룹 미가입 사용자 접근 → 403, 빈 기간 → 빈 배열 반환 |
| 관련 화면 | SCR-007 (캘린더 뷰) |
| 관련 API | API-020 (GET /groups/:id/schedules) |

### F-004. 일정 CRUD

| 항목 | 내용 |
|------|------|
| 설명 | 그룹 캘린더에 일정 등록, 상세 조회, 수정, 삭제 |
| 입력 | 제목 (필수, 최대 50자), 시작/종료 날짜·시간, 색상 태그, 그룹 ID |
| 처리 | schedules 테이블 INSERT/UPDATE/DELETE. 수정·삭제 시 등록자 또는 오너만 허용 |
| 출력 | 생성/수정된 일정 객체 또는 삭제 확인 |
| 예외 처리 | 권한 없는 수정/삭제 → 403, 존재하지 않는 일정 → 404, 종료일 < 시작일 → 400 |
| 관련 화면 | SCR-008 (일정 등록), SCR-009 (일정 상세) |
| 관련 API | API-021 (POST /schedules), API-022 (GET /schedules/:id), API-023 (PUT /schedules/:id), API-024 (DELETE /schedules/:id) |

### F-005. 다이어리 꾸미기 - 텍스트

| 항목 | 내용 |
|------|------|
| 설명 | 일정 상세에 자유 형식 텍스트 메모 작성 및 저장 |
| 입력 | 텍스트 (최대 2,000자) |

| 예외 처리 | 2,000자 초과 → 400, XSS 방지를 위한 HTML 이스케이프 처리 |
| 관련 화면 | SCR-009 (일정 상세 - 텍스트 입력 영역) |
| 관련 API | API-030 (POST /schedules/:id/contents) |

### F-006. 다이어리 꾸미기 - 사진

| 항목 | 내용 |
|------|------|
| 설명 | 일정 상세에 사진 다중 업로드, 갤러리 형태로 표시 |
| 입력 | 이미지 파일 (JPEG/PNG/WEBP, 최대 10MB/장, 최대 10장) |
| 처리 | Supabase Storage에 업로드. schedule_contents 테이블에 type='image', url 저장. 클라이언트에서 WebP 압축 후 업로드 |
| 출력 | 업로드된 이미지 URL 목록 |
| 예외 처리 | 용량 초과 → 400, 지원하지 않는 형식 → 415, 10장 초과 → 400, Storage 오류 → 500 |
| 관련 화면 | SCR-009 (일정 상세 - 사진 갤러리) |
| 관련 API | API-031 (POST /schedules/:id/upload/image) |

### F-007. 다이어리 꾸미기 - 이모지

| 항목 | 내용 |
|------|------|
| 설명 | 일정 대표 이모지를 이모지 피커로 선택. 캘린더 뷰에서 일정 아이콘으로 표시 |
| 입력 | 이모지 유니코드 문자 |
| 처리 | schedules 테이블 emoji 컬럼에 저장. 캘린더 뷰 렌더링 시 이모지 아이콘 표시 |
| 출력 | 저장된 이모지, 캘린더 뷰에서 이모지 아이콘 표시 |
| 예외 처리 | 유효하지 않은 이모지 코드 → 400 |
| 관련 화면 | SCR-008 (일정 등록 - 이모지 피커), SCR-007 (캘린더 뷰 - 이모지 아이콘) |
| 관련 API | API-023 (PUT /schedules/:id) |

### F-008. 다이어리 꾸미기 - 지도

| 항목 | 내용 |
|------|------|
| 설명 | Kakao Map API를 통해 장소를 검색하고 일정 상세에 지도 핀으로 첨부 |
| 입력 | 장소명 또는 주소 검색어 |
| 처리 | Kakao Map 장소 검색 API 호출 → 결과 선택 → schedule_contents 테이블에 type='location', lat/lng/name 저장 |
| 출력 | 지도 핀 표시 (Kakao Map 임베드), 장소명·주소 텍스트 |
| 예외 처리 | Kakao Map API 오류 → 503 (사용자에게 "지도 서비스 일시 중단" 안내), 검색 결과 없음 → 빈 목록 반환 |
| 관련 화면 | SCR-009 (일정 상세 - 지도 영역) |
| 관련 API | API-032 (POST /schedules/:id/contents, type=location) |

---

### F-009. 다이어리 꾸미기 - URL 카드

| 항목 | 내용 |
|------|------|
| 설명 | URL 입력 시 OG 태그를 파싱하여 제목·설명·이미지가 포함된 카드로 표시 |
| 입력 | 외부 URL (http/https) |
| 처리 | 서버 사이드에서 URL fetch → OG meta 태그 파싱 (og:title, og:description, og:image) → schedule_contents 테이블에 type='url', og_data JSON 저장 |
| 출력 | OG 카드 (썸네일 + 제목 + 설명 + 도메인), Fallback: URL 텍스트 링크 |
| 예외 처리 | 접근 불가 URL → Fallback 처리, OG 태그 없음 → 제목만 URL로 표시, 타임아웃 (5초) → Fallback |
| 관련 화면 | SCR-009 (일정 상세 - URL 카드 영역) |
| 관련 API | API-033 (POST /schedules/:id/contents, type=url) |

### F-010. 다이어리 꾸미기 - 영상

| 항목 | 내용 |
|------|------|
| 설명 | YouTube URL 임베드 또는 영상 파일 직접 업로드 |
| 입력 | YouTube URL 또는 영상 파일 (MP4, 최대 100MB) |
| 처리 | YouTube URL: youtube-url에서 video ID 추출 → iframe 임베드. 파일: Supabase Storage 업로드 → video 태그 |
| 출력 | 영상 플레이어 (YouTube iframe 또는 HTML5 video 태그) |
| 예외 처리 | 유효하지 않은 YouTube URL → 400, 파일 100MB 초과 → 400, 지원하지 않는 형식 → 415 |
| 관련 화면 | SCR-009 (일정 상세 - 영상 영역) |
| 관련 API | API-034 (POST /schedules/:id/upload/video) |

### F-011. 앱 내 알림

| 항목 | 내용 |
|------|------|
| 설명 | 그룹 내 일정 등록·수정·삭제 시 구성원 전체에게 앱 내 알림 전송 |
| 입력 | 알림 유형 (SCHEDULE_CREATED / SCHEDULE_UPDATED / SCHEDULE_DELETED), 일정 ID |
| 처리 | 일정 변경 이벤트 발생 시 group_members에서 멤버 목록 조회 → notifications 테이블에 각 멤버별 알림 INSERT. Supabase Realtime으로 클라이언트에 push |
| 출력 | 알림 뱃지 카운트 업데이트, 알림 목록에 새 항목 추가 |
| 예외 처리 | Realtime 연결 끊김 → 재연결 시 미읽음 알림 일괄 조회, 알림 발송 실패 → 로그 기록 후 재시도 |
| 관련 화면 | SCR-010 (알림 목록) |
| 관련 API | API-040 (GET /notifications), API-041 (PATCH /notifications/:id/read), API-042 (PATCH /notifications/read-all) |
