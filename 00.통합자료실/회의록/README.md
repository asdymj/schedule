# 회의록

> 킥오프, 주간회의, 이해관계자 미팅 기록 저장

## 파일명 규칙

`MTG-YYYYMMDD_회의유형_요약.md`

| 회의 유형 | 파일명 예시 | 주차 |
|-----------|------------|------|
| 킥오프 | MTG-20260524_킥오프_프로젝트개시.md | W1 |
| 주간회의 | MTG-20260531_주간_W2진척.md | W2~ |
| 설계 리뷰 | MTG-20260607_설계리뷰_DB스키마.md | W3 |
| 중간보고 | MTG-20260614_중간보고_M2.md | W3 말 |
| 베타 회고 | MTG-20260621_베타회고_피드백.md | W4 |
| 종료 회고 | MTG-20260628_종료회고_M5.md | W5 |

## 회의록 템플릿

```markdown
# 회의록 - {{회의명}}

- **일시**: YYYY-MM-DD HH:MM
- **장소**: (대면 / Zoom / Slack Huddle)
- **참석자**: PM, 개발자, 기획자

## 1. 안건
## 2. 논의
## 3. 결정사항
| # | 결정 | 책임자 | 기한 |
## 4. Action Items
| # | 작업 | 담당 | 기한 |
## 5. 다음 회의
```
