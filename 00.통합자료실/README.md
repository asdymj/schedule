# 통합자료실

> NotebookLM 연동 프로젝트 참조 자료 저장소
> 이 폴더의 자료를 NotebookLM에 소스로 등록하면 AI 기반 조회/요약/분석이 가능합니다.

## 폴더 구조

| 폴더 | 용도 |
|------|------|
| 고객자료/ | RFP, 사업 브리프, 고객 요구사항 |
| 정책자료/ | 법규, 가이드라인, 사내 표준, 보안 정책 |
| 인프라자료/ | 서버 구성, 네트워크, DB, 배포 환경 문서 |
| 회의록/ | 킥오프, 주간회의, 이해관계자 미팅 기록 |
| 참고자료/ | 경쟁사 분석, 벤치마킹, 기술 조사, NLM 동기화 자료 |

## NotebookLM 연동 방법

1. NotebookLM(notebooklm.google.com)에서 새 노트북 생성
2. 노트북 ID를 `.AP-key.md`에 기록
3. 자료 등록: `nlm source add <notebook_id> --text "내용" --title "제목"`
4. 또는 MCP `source_add` 도구 사용

## 등록 우선순위

1. schedulePRD.md (프로젝트 요구사항)
2. 착수보고서 (01.관리문서/)
3. 마켓리서치, 서비스기획서 (02.기획문서/)
4. 이후 산출물 완료 시 순차 등록 (Gate-Check 자동 연동)
