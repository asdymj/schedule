## 개요

스마트폰 하나로 손쉽게 일기를 쓸 수 있는 시대가 도래했습니다. 이 글은 20대를 위한 감성 가득한 무료 일기 앱 4가지를 비교 분석합니다.

## 추천 앱 목록

### 1. 굿다이어리(Goodiary)
- 감성적 UI와 직관적 인터페이스 제공
- 실시간 동기화 기능으로 여러 기기에서 동시에 이용 가능
- 아이폰, 아이패드, 맥, 안드로이드, 윈도우 지원
- 국산 앱으로 한글 지원 우수

### 2. 저니(Journey)
- 감정 태깅 기능으로 감정 기록
- 위치 기반 기능으로 여행 기록이나 특정 장소 기억에 좋음
- 멀티플랫폼 지원(유료 동기화)

### 3. 데이원(Day One)
- 심플하면서 고급스러운 디자인
- 자동 날씨·위치 기록, 사진 첨부 등 일상 기록에 진심
- 최근 윈도우 지원 시작(유료 기능)

### 4. 다이어리움(Diarium)
- SNS 연동으로 통합 기록 관리
- 음성 녹음 및 오디오 일기를 지원
- PC와 모바일 간 실시간 동기화

## 선택 가이드

| 사용자 니즈 | 추천 앱 |
|---|---|
| 무료 멀티플랫폼 | Goodiary |
| SNS 연동 | Journey, Diarium |
| 감성 UI 중시 | Goodiary |
| 심플 + 고급 기능 | Day One |

## 프로젝트 시사점

다이어리 앱은 이미 포화 시장이나, 차별화 포인트는 ①멀티플랫폼 동기화, ②감정/위치 태깅, ③SNS 연동, ④음성 입력 등이다. 본 프로젝트는 "그룹 공유 + 다이어리 꾸미기"라는 미충족 영역에 진입한다.
