## 도입 배경

마이크로소프트 2024년 조사에 따르면 회의 시간이 **252% 증가**했고, 직장인은 주평균 21.5시간을 회의에 사용합니다. 수기 기록의 정보 손실 문제로 AI 회의록 자동화 도구가 주목받고 있습니다.

## TOP 5 추천 도구 비교

### 1. Otter.ai — 영어 안정성 중심
- 음성 인식 정확도 97% 이상, 화자 자동 식별
- Zoom/Teams/Google Meet 완벽 통합
- 무료: 월 10시간 / 비즈니스: $20/월
- 한계: 한국어 대응 제한

### 2. Notta — 다국어 대응
- 100+ 언어 지원, 아시아 언어 강점
- 화면 공유 텍스트 추출 기능
- 무료: 월 30분 / 프로: $16.99/월
- 모바일 대응 충실

### 3. Fathom — CRM 연동 특화
- 영업팀 대상, Salesforce/HubSpot 통합
- 고객 감정 분석으로 영업 기회 자동 식별
- $29/월/사용자

### 4. Fireflies.ai — 무료 플랜 충실
- 월 8시간 무료 녹음
- 40+ 앱 연동, 강력한 검색 기능
- 무료: 월 8시간 / 프로: $18/월

### 5. Kopi.ai — 한국어 특화
- 한국어 정확도 98% 이상
- 업종별 기능 탑재
- 무료: 월 5시간 / 프로: 19,000원/월

## 도입 가이드

1. 협업 툴(Slack, Notion 등)과의 호환성 확인
2. 전원에게 녹음 사실 통지 (프라이버시)
3. 기밀 정보 제외 옵션 사용
4. AI 단독 의존 X — 인간 검증 병행 권장

## 프로젝트 시사점

본 프로젝트의 **회의록(00.통합자료실/회의록/)** 자동 작성에 활용 가능. 특히 한국어 회의가 많다면 Kopi.ai 또는 Notta 우선 검토. 회의록 자동 요약 → NotebookLM 소스 자동 등록 워크플로우로 확장 시 W2 단계에서 도입 가능.
