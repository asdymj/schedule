## 평가 기준

블로거가 중요시한 3가지 기능:
1. 데이트 기록 캘린더
2. 일일 대화 프롬프트
3. 핫스팟/데이트 코스 추천

## 앱별 리뷰

### 1. SomOne (썸원)
- 일일 관계 질문 특화. 답변을 파트너와 공유해 대화 유도
- 인터페이스에 성장하는 가상 펫(귀여움 강조)
- 단점: 핵심 기능 외 부가 기능 부족, 프리미엄 가치 낮음

### 2. Between (비트윈)
- 메시징 중심 커플 앱. 인앱 채팅 + 사진 공유
- 단점: 사진 검색 기능 부실, 메시징 기능 분절, 일반 메신저 대비 차별점 약함

### 3. Lovda (럽다)
- **다이어리 중심** + 사진 첨부 + 테마 커스텀 + 캘린더 통합
- 일일 질문, 밸런스 게임 포함
- 채팅 내 사진 공유는 광고 시청 필요
- 월 구독 약 3,000원

### 4. Memory Tree (기억나무)
- 올인원 솔루션 시도: 일일 질문 + 일기 + 캘린더 + 정원 꾸미기
- 인터페이스는 경쟁사 대비 세련도 낮음
- 평생 이용권 9,900원

### 5. DatePop (데이트팝)
- 데이트 장소/핫스팟 추천 특화 (지역/테마별)
- 서울/부산 등 대도시 위주, 교외 사용자 활용도 낮음

## 결론

각 앱이 다른 니즈를 충족 → 사용자가 여러 앱을 병행 사용하는 경향. **올인원 솔루션의 시장 기회 존재**.

## 프로젝트 시사점

본 프로젝트의 직접 경쟁군: Lovda(다이어리 + 캘린더 통합), Memory Tree(올인원). 차별화 포인트:
- **친구/가족/동호회 등 다양한 그룹 단위** (커플 한정 X)
- **멀티미디어 데코** (지도/영상/URL 카드) — 다른 커플 앱들이 약한 영역
- 50명까지 확장 가능한 그룹 구조
