# doc-report: 전문 보고서 문서 생성기

마크다운을 **전문적인 기획 보고서 스타일**의 Word 문서로 변환하는 에이전트입니다.

## 주요 기능

### 자동 생성 요소
- **표지 페이지**: 제목, 부제목, 메타 정보 테이블, 기밀 문구
- **목차**: 3단계 제목 기반 자동 생성
- **번호 제목**: 1. → 1.1 → 1.1.1 체계
- **정보 박스**: `:::info` 회색 배경 박스
- **경고 박스**: `:::warning` 노란 배경 박스
- **표**: 헤더 스타일, 정렬 지원
- **플로우 다이어그램**: `:::flow` 화살표 연결 박스

## 사용법

### CLI 실행 (전역)
```bash
# 어디서든 실행 가능 (pip editable install 완료)
python3 -m doc_report input.md output.docx
```

### 옵션
```bash
python3 -m doc_report input.md output.docx --style kb --logo /path/to/logo.png
```

| 옵션 | 설명 |
|------|------|
| `--style`, `-s` | 스타일 선택 (`default`, `kb`) |
| `--logo`, `-l` | 표지 로고 이미지 경로 |

### 스타일 선택 기준 (중요)

**항상 `--style kb`를 기본으로 사용하세요.** KB 스타일이 범용적이고 완성도가 높습니다.

| 스타일 | 폰트 | 자동 번호 | 용도 |
|--------|------|-----------|------|
| `kb` (권장) | Pretendard | OFF (원본 유지) | 마크다운에 이미 번호가 있는 문서, 대부분의 기획서 |
| `default` | 맑은 고딕 | ON (1. → 1.1 자동) | 번호 없는 순수 마크다운 |

- 마크다운에 `1.`, `1.1`, `1.1.1` 등 번호가 이미 있으면 → 반드시 `--style kb`
- 번호 없이 `#`, `##`, `###` 만 사용한 마크다운 → `--style default` 가능

## 마크다운 문법

### YAML 메타데이터 (표지 정보)
```yaml
---
title: 대제목
subtitle: 부제목
description: 설명문
project: 프로젝트명
date: 2026-01-05
version: v1.0
author: 작성자
confidential: true
---
```

### 제목 (자동 번호)
```markdown
# H1 제목       → "1. H1 제목"
## H2 제목      → "1.1 H2 제목"
### H3 제목     → "1.1.1 H3 제목"
```

### 정보 박스
```markdown
:::info 핵심 키워드
NL2SQL | AWS Bedrock | 하이브리드 검색
:::
```

### 경고 박스
```markdown
:::warning 중요 사항
이 내용은 기밀입니다.
:::
```

### 플로우 다이어그램
```markdown
:::flow 그림 1: 시스템 구조
입력 -> 처리 -> LLM -> 출력
:::
```

### 표
```markdown
| 항목 | 내용 |
|:---:|------|
| 1장 | 개요 |
| 2장 | 설계 |
```

## 스타일 가이드

### 색상 팔레트

#### 브랜드 & 텍스트
| 용도 | HEX | 미리보기 |
|------|-----|----------|
| 브랜드 블루 (강조) | `#2B579A` | 제목, 링크 |
| 본문 텍스트 | `#1A1A1A` | 기본 텍스트 |
| 진한 회색 | `#333333` | 부제목 |
| 중간 회색 | `#666666` | 보조 텍스트 |
| 연한 회색 | `#999999` | 캡션 |

#### 배경색
| 용도 | HEX | 미리보기 |
|------|-----|----------|
| 정보박스 (info) | `#F5F5F5` | 연한 회색 |
| 경고박스 (warning) | `#FFF9C4` | 파스텔 노랑 |
| 표 헤더 | `#E8E8E8` | 밝은 회색 |
| 흰색 배경 | `#FFFFFF` | 기본 배경 |

#### 테두리
| 용도 | HEX | 미리보기 |
|------|-----|----------|
| 일반 테두리 | `#CCCCCC` | 표, 정보박스 |
| 경고박스 테두리 | `#FFD54F` | 노랑 계열 |
| 진한 테두리 | `#999999` | 강조용 |
