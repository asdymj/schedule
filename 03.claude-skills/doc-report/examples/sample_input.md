# Executive Summary

## 문서 개요

본 문서는 KB자산운용 RISE ETF 홈페이지에 도입할 **AI 챗봇 서비스**의 기획안이다. 솔트록스(리본홀딩스, 프렌티스)가 담당하는 RFP 2.1~2.4 영역의 기술 설계와 구현 방향을 정리한다.

:::info 핵심 키워드
NL2SQL (자연어→SQL 변환) | 하이브리드 검색 (SQL + Graph + RAG) | AWS Bedrock | 가드레일
:::

# 프로젝트 개요

## 프로젝트 배경

### 시장 상황

국내 ETF 시장은 급성장 중이며, 개인 투자자의 관심이 높아지고 있다. 그러나 ETF 상품 수가 700개를 넘어가면서 투자자들이 적합한 상품을 찾기 어려워졌다.

:::flow 그림 1: ETF 시장 문제와 AI 솔루션
ETF 700+ 상품 -> 정보 과부하 -> 선택 어려움 -> AI 챗봇 솔루션
:::

### 프로젝트 추진 배경

KB자산운용은 RISE ETF 브랜드의 경쟁력 강화를 위해 홈페이지 전면 리뉴얼을 추진하고 있다. 이 프로젝트의 핵심은 AI 기반 서비스 도입을 통한 고객 경험 혁신이다.

## 프로젝트 목적

본 프로젝트의 핵심 목표는 **KB RISE ETF 노출 극대화**를 통해 투자자들이 타 증권사 앱에서 RISE ETF를 구매하도록 유도하는 것이다.

:::warning 핵심 전략
KB자산운용은 **운용사**로서 직접 판매 권한이 없다. 따라서 AI 챗봇을 통한 정보 제공과 추천 서비스로 고객 접점을 강화하는 전략을 취한다.
:::

## 프로젝트 범위

본 문서는 솔트록스 컨소시엄(리본홀딩스, 프렌티스)이 담당하는 **AI 기능 개발** 영역을 다룬다.

| 역할 | 담당사 | 범위 |
|------|--------|------|
| 플러스X | 디자인 하우스 | 홈페이지 전체 리뉴얼 (디자인/퍼블리싱) |
| 솔트록스 | AI 총괄 | 프로젝트 관리, 품질 보증 |
| 리본홀딩스 + 프렌티스 | AI 기획/개발 | RFP 2.1~2.4 AI 기획 및 개발 |

# 기술 스택

## 확정 기술 스택

### 기술 선택 원칙

기술 선택 시 다음 원칙을 적용하였다:

- **검증된 기술**: 프로덕션 환경에서 안정성이 입증된 기술
- **확장성**: 트래픽 증가에 유연하게 대응 가능
- **비용 효율**: 초기 비용과 운영 비용의 균형

### 기술 스택 요약

| 영역 | 기술 | 선택 근거 |
|------|------|----------|
| LLM | Claude Sonnet 4.5 | 한국어 성능, 비용 효율 |
| 컨테이너 | ECS + Fargate | 서버리스, 관리 용이 |
| 프론트엔드 | React | KB 내부 표준, 생태계 |
| 데이터베이스 | PostgreSQL | ACID, JSON 지원 |
| 벡터 DB | Pinecone | 관리형 서비스 |
