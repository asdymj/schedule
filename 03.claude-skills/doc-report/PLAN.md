# doc-report 에이전트 기획서

## 1. 개요

### 1.1 목적
마크다운 또는 텍스트 입력을 받아 **전문적인 기획 보고서 스타일**의 Word 문서(.docx)를 자동 생성하는 에이전트

### 1.2 참조 스타일
`KB자산운용-AI기획-20260105.pdf` 문서 스타일 기반

---

## 2. 문서 스타일 분석

### 2.1 표지 (Cover Page)
```
┌─────────────────────────────────────────────┐
│                                             │
│              [회사 로고]                      │
│                                             │
│            ▌대제목 (Bold, 36pt)              │
│            ▌부제목 (Bold, 28pt)              │
│                                             │
│            설명문 (Regular, 14pt)            │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │ 프로젝트  │ 프로젝트명                    │  │
│  │ 작성일    │ 2026-01-05                  │  │
│  │ 버전      │ v1.0                        │  │
│  │ 작성      │ 작성자                       │  │
│  └───────────────────────────────────────┘  │
│                                             │
│      Confidential - Internal Use Only       │
└─────────────────────────────────────────────┘
```

### 2.2 목차 (Table of Contents)
- **제목**: "0. 목차"
- **번호 체계**: 1 → 1.1 → 1.1.1 (3단계)
- **점선 리더**: 제목과 페이지 번호 연결
- **들여쓰기**: 레벨별 차등

### 2.3 본문 제목 스타일

| 레벨 | 형식 | 예시 | 폰트 |
|------|------|------|------|
| H1 | `N. 제목` | 1. Executive Summary | Bold, 24pt |
| H2 | `N.N 제목` | 1.1 문서 개요 | Bold, 18pt |
| H3 | `N.N.N 제목` | 1.1.1 문서 구성 | Bold, 14pt |

### 2.4 특수 요소

#### 2.4.1 정보 박스 (Callout Box)
```
┌─────────────────────────────────────────────┐
│ ℹ️ 핵심 키워드                                │  ← 회색 배경 (#F5F5F5)
│                                             │
│ NL2SQL | 하이브리드 검색 | AWS Bedrock        │
└─────────────────────────────────────────────┘
```

#### 2.4.2 경고/중요 박스
```
┌─────────────────────────────────────────────┐
│ ❗ RFP 핵심 요건 (2.1 ~ 2.4)                   │  ← 연노랑 배경 (#FFF9E6)
│                                             │
│ 솔트록스 컨소시엄이 담당하는 4개 핵심 요건...     │
└─────────────────────────────────────────────┘
```

#### 2.4.3 표 (Table)
- 헤더: 회색 배경 (#E8E8E8), 중앙 정렬, Bold
- 본문: 흰색 배경, 테두리 회색 (#CCCCCC)
- 셀 패딩: 상하 8pt, 좌우 12pt

#### 2.4.4 플로우 다이어그램
```
┌─────────┐    ┌─────────┐    ┌─────────┐
│ Step 1  │ → │ Step 2  │ → │ Step 3  │
└─────────┘    └─────────┘    └─────────┘
              그림 N: 캡션 텍스트
```
- 박스: 둥근 모서리, 회색 테두리
- 화살표: 검정, 단방향
- 캡션: 중앙 정렬, 이탤릭

### 2.5 색상 팔레트

| 용도 | 색상 | HEX |
|------|------|-----|
| 브랜드 (강조) | 파란색 | #2B579A |
| 본문 | 검정 | #1A1A1A |
| 부제목 | 진회색 | #333333 |
| 정보박스 배경 | 연회색 | #F5F5F5 |
| 경고박스 배경 | 연노랑 | #FFF9E6 |
| 표 헤더 | 회색 | #E8E8E8 |
| 테두리 | 연회색 | #CCCCCC |

### 2.6 폰트 시스템

| 용도 | 폰트 | 대체 |
|------|------|------|
| 제목 | Pretendard | Arial |
| 본문 | Pretendard | Arial |
| 코드 | Consolas | Courier New |

## 3. 마크다운 문법 확장

### 3.1 표준 마크다운 지원
- `# ~ ######` 제목
- `**bold**`, `*italic*`, `` `code` ``
- `- 불릿`, `1. 번호`
- `> 인용`
- `| 표 |`
- `---` 구분선
- `[링크](url)`

### 3.2 확장 문법 (커스텀)

#### 메타데이터 블록 (YAML Front Matter)
```yaml
---
title: KB RISE ETF
subtitle: AI 챗봇 서비스 기획
description: 초기 킥오프 내부 공유용
project: KB자산운용 AI ETF
date: 2026-01-05
version: v1.0
author: Frentis
confidential: true
logo: /path/to/logo.png
---
```

#### 정보 박스
```markdown
:::info 핵심 키워드
NL2SQL | 하이브리드 검색 | AWS Bedrock
:::
```

#### 경고 박스
```markdown
:::warning RFP 핵심 요건
솔트록스 컨소시엄이 담당하는 요건...
:::
```

#### 플로우 다이어그램
```markdown
:::flow 그림 1: ETF 시장 문제와 AI 솔루션
ETF 700+ 상품 -> 정보 과부하 -> 선택 어려움 -> AI 챗봇 솔루션
:::
```

#### 페이지 나누기
```markdown
<!-- pagebreak -->
```

## 4. 아키텍처

### 4.1 모듈 구조
```
doc-report/
├── __init__.py
├── parser/
│   ├── markdown_parser.py    # 마크다운 파싱
│   ├── yaml_parser.py        # 메타데이터 파싱
│   └── custom_blocks.py      # 확장 문법 파싱
├── generator/
│   ├── docx_generator.py     # Word 문서 생성
│   ├── cover_page.py         # 표지 생성
│   ├── toc_generator.py      # 목차 생성
│   ├── table_generator.py    # 표 생성
│   ├── callout_box.py        # 정보/경고 박스
│   └── flow_diagram.py       # 플로우 다이어그램
├── styles/
│   ├── default_style.py      # 기본 스타일 정의
│   └── colors.py             # 색상 팔레트
├── templates/
│   └── frentis_template.docx # 기본 템플릿 (선택)
├── cli.py                    # CLI 인터페이스
└── agent.py                  # 메인 에이전트
```

### 4.2 처리 흐름
```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ Markdown    │ →  │ Parser      │ →  │ AST         │
│ Input       │     │ (확장문법)   │     │ (구조화)     │
└─────────────┘     └─────────────┘     └─────────────┘
                                              ↓
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ DOCX        │ ←  │ Generator   │ ←  │ Style       │
│ Output      │     │ (python-docx)│    │ Application │
└─────────────┘     └─────────────┘     └─────────────┘
```

## 5. 핵심 기능

### 5.1 Phase 1 (MVP)
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 메타데이터 표지 | YAML → 표지 페이지 | P0 |
| 자동 목차 | 제목 기반 TOC | P0 |
| 제목 스타일 | H1-H3 번호 체계 | P0 |
| 표 생성 | 마크다운 표 → Word 표 | P0 |
| 정보 박스 | :::info 문법 | P0 |

### 5.2 Phase 2 (확장)
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 경고 박스 | :::warning 문법 | P1 |
| 플로우 다이어그램 | :::flow 문법 | P1 |
| 이미지 삽입 | `![alt](path)` | P1 |
| 페이지 번호 | 푸터 자동 삽입 | P1 |

### 5.3 Phase 3 (고급)
| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 로고 삽입 | 표지 로고 | P2 |
| 템플릿 시스템 | 커스텀 템플릿 | P2 |
| PDF 내보내기 | DOCX → PDF 변환 | P2 |
| 다국어 지원 | 영문/한글 자동 감지 | P2 |

## 6. 사용 예시

### 6.1 CLI 사용법
```bash
# 기본 변환
python -m doc_report input.md output.docx

# 옵션 지정
python -m doc_report input.md output.docx \
  --template frentis \
  --logo /path/to/logo.png \
  --toc true
```

### 6.2 입력 예시 (input.md)
```markdown
---
title: 프로젝트명
subtitle: 부제목
project: 클라이언트 프로젝트
date: 2026-02-04
version: v1.0
author: 작성자
confidential: true
---

# Executive Summary

## 문서 개요

본 문서는 프로젝트 기획안이다.

:::info 핵심 키워드
AI | 챗봇 | NL2SQL
:::

### 문서 구성

| 장 | 내용 |
|----|------|
| 1장 | 개요 |
| 2장 | 설계 |

:::flow 그림 1: 시스템 구조
사용자 -> 챗봇 -> LLM -> 응답
:::

## 프로젝트 목적

:::warning 중요 사항
이 프로젝트는 기밀입니다.
:::
```

### 6.3 출력 결과
- 표지 페이지 (메타데이터 기반)
- 자동 생성 목차
- 번호 매겨진 제목들
- 스타일 적용된 표
- 정보/경고 박스
- 플로우 다이어그램
- 페이지 번호
