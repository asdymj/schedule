# 딥 리서치 엔진

여러 소스를 병렬로 조사하여 종합적인 리서치 리포트를 제공합니다.

## 리서치 전략

### Phase 1: 다각도 검색 (병렬 실행)

**5개 검색 관점:**

1. **일반 검색**
   - 주제에 대한 개요 및 최신 정보
   - 쿼리: `{주제} 2026`

2. **기술/심화 검색**
   - 기술적 세부사항, 구현 방법
   - 쿼리: `{주제} technical deep dive tutorial`

3. **비교/대안 검색**
   - 대안, 경쟁자, 장단점 비교
   - 쿼리: `{주제} vs alternatives comparison pros cons`

4. **사례/실전 검색**
   - 실제 사용 사례, 성공/실패 사례
   - 쿼리: `{주제} case study real world example`

5. **최신 동향 검색**
   - 최신 뉴스, 트렌드, 미래 전망
   - 쿼리: `{주제} latest news trends 2026`

### Phase 2: 심층 분석

검색 결과에서 발견한 중요한 소스에 대해:
- WebFetch로 상세 내용 수집
- 핵심 정보 추출 및 정리
- 출처 간 교차 검증

### Phase 3: 종합 리포트 작성

## 리포트 형식

```markdown
# [주제] 딥 리서치 리포트

## Executive Summary
핵심 발견사항 3-5개 bullet point

## 1. 개요
- 정의 및 배경
- 현재 상황

## 2. 핵심 분석
### 2.1 기술적 측면
- 작동 원리
- 주요 기술/방법론

### 2.2 시장/트렌드
- 현재 동향
- 주요 플레이어

### 2.3 장단점 분석
| 장점 | 단점 |
|------|------|
| ... | ... |

## 3. 비교 분석
### 대안/경쟁자
| 항목 | A | B | C |
|------|---|---|---|
| 특징1 | | | |
| 특징2 | | | |

## 4. 실전 사례
### 성공 사례
- 사례 1: ...
- 사례 2: ...

### 주의사항/실패 사례
- ...

## 5. 결론 및 권장사항
- 핵심 takeaway
- 추천 액션

## 참고 자료
- [출처1](URL)
- [출처2](URL)
...

---
*리서치 수행 일시: {날짜}*
*검색 쿼리 수: {N}개*
*분석 소스 수: {M}개*
```

## 품질 기준

1. **신뢰성**: 공식 문서, 신뢰할 수 있는 출처 우선
2. **최신성**: 2024-2026년 자료 우선
3. **다양성**: 다양한 관점 포함
4. **실용성**: 실행 가능한 인사이트 제공
5. **출처 명시**: 모든 주장에 출처 표기

## 실행

조사 주제: $ARGUMENTS

1. 위 5가지 관점으로 병렬 검색을 수행하세요 (WebSearch 5회 동시 호출)
2. 검색 결과를 분석하고 중요 소스를 식별하세요
3. 필요시 WebFetch로 상세 정보를 수집하세요
4. 종합 리포트를 작성하세요
5. 모든 출처를 명시하세요
