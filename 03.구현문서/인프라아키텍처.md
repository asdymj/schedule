## 1. 시스템 구성도

```
[클라이언트 (모바일 웹 브라우저)]
    |  HTTPS
    v
[Vercel Edge Network (CDN)]
    |
    v
[Next.js App (Vercel Serverless)]
    ├── /app/*          (프론트엔드 페이지)
    └── /app/api/*      (API Routes - M1~M4 통합)
    |
    ├── [Supabase PostgreSQL]  (DB)
    ├── [Supabase Storage]     (미디어 파일)
    ├── [Supabase Auth]        (JWT 인증)
    └── [Supabase Realtime]    (알림 WebSocket)
    |
    └── [Kakao Map API]        (지도/위치 검색)
```

---

## 2. 서버 구성 (M1~M4 기본값)

| 구분 | 환경 | 사양 | 용도 |
|------|------|------|------|
| 프론트엔드 + API | Vercel (서버리스) | Lambda 60초 / 3008MB | 페이지 렌더링 + API Routes |
| 데이터베이스 | Supabase PostgreSQL | Supabase Pro 플랜 | 데이터 저장 |
| 파일 스토리지 | Supabase Storage | S3 호환 | 사진·영상 파일 저장 |
| 인증 | Supabase Auth | - | JWT 발급·검증 |
| 실시간 | Supabase Realtime | WebSocket | 알림 실시간 전송 |

> **M5 분리 검토 트리거**: Vercel Lambda 60초 초과(대용량 영상 처리), 동시 접속 500명 초과, 월 함수 호출 Vercel Pro 한도 초과 시 Express.js 백엔드 분리 검토

## 5. CI/CD 파이프라인

```
GitHub Push (main 브랜치)
    |
    v
GitHub Actions
    ├── 1. npm install
    ├── 2. ESLint 검사
    ├── 3. TypeScript 타입 검사 (tsc --noEmit)
    ├── 4. Jest 단위 테스트
    └── 5. Vercel 배포 트리거
    |
    v
Vercel 자동 배포
    ├── Next.js 빌드
    ├── 환경변수 주입
    └── 서버리스 함수 배포
```

## 6. 환경변수 관리

| 변수명 | 설명 | 등록 위치 |
|--------|------|-----------|
| NEXT_PUBLIC_SUPABASE_URL | Supabase 프로젝트 URL | Vercel 환경변수 |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | Supabase 공개 키 | Vercel 환경변수 |
| SUPABASE_SERVICE_ROLE_KEY | Supabase 서버 키 (서버 사이드만) | Vercel 환경변수 |
| JWT_SECRET | JWT 서명 키 | Vercel 환경변수 |
| NEXT_PUBLIC_KAKAO_MAP_KEY | Kakao Map JavaScript 키 | Vercel 환경변수 |
| KAKAO_CLIENT_ID | Kakao OAuth 클라이언트 ID | Vercel 환경변수 |
| GOOGLE_CLIENT_ID | Google OAuth 클라이언트 ID | Vercel 환경변수 |
| GOOGLE_CLIENT_SECRET | Google OAuth 시크릿 | Vercel 환경변수 |
