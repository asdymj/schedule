# 시스템 정의서

**프로젝트명**: 온라인 다이어리 꾸미기 (Share Diary Calendar)
**작성일**: 2026-05-24

---

## 1. 기술 스택

| 영역 | 기술 | 버전 | 비고 |
|------|------|------|------|
| Frontend | Next.js + Tailwind CSS | Next.js 15.x, Tailwind 3.x | V0.42 표준, App Router |
| Backend (M1~M4) | Next.js API Routes | 15.x | src/frontend/app/api/* |
| Database | PostgreSQL (Supabase) | PostgreSQL 15 | Supabase 호스팅 |
| Auth | Supabase Auth | - | JWT + OAuth |
| Storage | Supabase Storage | - | 미디어 파일 저장 |
| Realtime | Supabase Realtime | - | 알림 WebSocket |
| Deploy | Vercel | - | V0.42 표준 |
| CI/CD | GitHub Actions | - | 표준 |
| 지도 | Kakao Map API | JavaScript SDK v3 | 장소 검색, 핀 표시 |
| 이모지 피커 | emoji-mart | 5.x | 이모지 선택 컴포넌트 |
| OG 파싱 | open-graph-scraper | - | URL 카드 미리보기 |

---

## 2. 모듈 구성

| 모듈명 | 역할 | 의존성 |
|--------|------|--------|
| auth | 회원 인증 (가입/로그인/소셜/JWT) | Supabase Auth, bcryptjs |
| groups | 그룹 생성/관리/초대 | auth, schedules |
| schedules | 일정 CRUD | auth, groups |
| contents | 일정 콘텐츠 관리 (사진/지도/URL/영상) | schedules, storage |
| notifications | 알림 생성/조회/읽음 | schedules, groups, Supabase Realtime |
| storage | Supabase Storage 파일 업로드/삭제 | Supabase Storage SDK |
| map | Kakao Map 장소 검색 및 임베드 | Kakao Map API |

## 4. 코딩 컨벤션

| 항목 | 규칙 |
|------|------|
| 언어 | TypeScript (strict mode) |
| 네이밍 (변수/함수) | camelCase |
| 네이밍 (컴포넌트) | PascalCase |
| 네이밍 (DB 컬럼) | snake_case |
| 들여쓰기 | 스페이스 2칸 |
| 린트 | ESLint (Next.js 기본) |
| 포맷터 | Prettier |
| 커밋 메시지 | 한국어: `[W4] 프론트엔드 - 로그인 페이지 생성` |
| 컴포넌트 구조 | 서버 컴포넌트 우선, 클라이언트 컴포넌트는 'use client' 명시 |

## 5. 에러 처리 규약

| HTTP 상태 | 의미 | 응답 형식 |
|-----------|------|-----------|
| 200 | 성공 | `{ "status": "success", "data": {...} }` |
| 201 | 생성 성공 | `{ "status": "success", "data": {...} }` |
| 400 | Bad Request | `{ "status": "error", "code": "BAD_REQUEST", "message": "..." }` |
| 401 | Unauthorized | `{ "status": "error", "code": "UNAUTHORIZED", "message": "..." }` |
| 403 | Forbidden | `{ "status": "error", "code": "FORBIDDEN", "message": "..." }` |
| 404 | Not Found | `{ "status": "error", "code": "NOT_FOUND", "message": "..." }` |
| 500 | Internal Error | `{ "status": "error", "code": "INTERNAL_ERROR", "message": "..." }` |

## 6. 보안 규약

| 항목 | 규칙 |
|------|------|
| 비밀번호 | bcryptjs salt rounds 12 |
| JWT | Access Token 1시간, Refresh Token 7일, HttpOnly Cookie |
| 파일 업로드 | 확장자 whitelist, 용량 제한 검증 (서버 사이드) |
| XSS | DOMPurify로 사용자 입력 텍스트 sanitize |
| SQL Injection | Supabase SDK (Prepared Statement 내장) |
| CORS | API Routes 동일 도메인, 별도 설정 불필요 |
| 환경변수 | 민감 정보는 서버 사이드 전용 (NEXT_PUBLIC_ 접두사 미사용) |
