# 디자인 스타일 가이드 (Design Style Guide)

**프로젝트명**: 온라인 다이어리 꾸미기 (Share Diary Calendar)
**작성일**: 2026-05-24
**버전**: v1.0

---

## 1. 디자인 원칙

1. **따뜻함**: 감성적이고 친근한 다이어리 느낌. 딱딱한 캘린더가 아닌 소중한 추억을 담는 공간
2. **간결함**: 콘텐츠(사진, 지도, 메모)가 주인공이 되도록 UI는 최소화
3. **접근성**: 누구나 쉽게 쓸 수 있는 직관적인 인터페이스, 모바일 퍼스트
4. **공유감**: 그룹 구성원이 함께 만드는 느낌. 아바타, 이름 표시로 공동 작업 강조

## 2. 글로벌 레이아웃

### 2.1 레이아웃 구조 (모바일 퍼스트)

```
+----------------------------+  375px
|  Header (56px)             |  그룹명, 알림, 액션 버튼
+----------------------------+
|                            |
|  Main Content              |  fluid, padding 16px
|  (스크롤 가능)               |
|                            |
+----------------------------+
|  Bottom Navigation (64px)  |  5개 메뉴
+----------------------------+
```

| 영역 | 크기 | 배경색 | 비고 |
|------|------|--------|------|
| 헤더 | H: 56px | #FFFFFF | 하단 border 1px #F0F0F0 |
| 콘텐츠 영역 | fluid | #FAF9F7 | 콘텐츠 배경 (아이보리 화이트) |
| 하단 내비게이션 | H: 64px + safe-area | #FFFFFF | 상단 border 1px #F0F0F0 |

### 2.2 스페이싱 스케일 (8px 기본 단위)

| 토큰 | 값 | 용도 |
|------|-----|------|
| xs | 4px | 아이콘-텍스트 간격 |
| sm | 8px | 인접 요소 간격 |
| md | 16px | 카드 내부 패딩, 화면 좌우 여백 |
| lg | 24px | 섹션 간 간격 |
| xl | 32px | 대형 섹션 간격 |

## 4. 타이포그래피

### 4.1 폰트 패밀리

| 용도 | 폰트 | 대체 |

### 4.2 타입 스케일

| 토큰 | 크기 | 행간 | 굵기 | 용도 |
|------|------|------|------|------|
| heading-1 | 22px | 30px | Bold (700) | 페이지 제목 |
| heading-2 | 18px | 26px | SemiBold (600) | 섹션 제목 |
| heading-3 | 16px | 24px | SemiBold (600) | 카드 제목 |

| body | 14px | 22px | Regular (400) | 본문, 일정 내용 |
| body-sm | 13px | 20px | Regular (400) | 보조 텍스트, 시간 |

## 6. 핵심 UI 컴포넌트

### 6.1 버튼

| Variant | 배경 | 텍스트 | 용도 |
|---------|------|--------|------|
| Primary | #FF6B9D | White | 주요 액션 (저장, 가입, 초대) |
| Secondary | White | #FF6B9D | 보조 액션 (취소) |
| Danger | #EF4444 | White | 삭제 |
| Ghost | 투명 | #FF6B9D | 텍스트 링크형 |

**크기**: sm (36px), md (44px), lg (52px)
**Border-radius**: 12px
**상태**: Default, Hover (10% 어둡게), Disabled (50% 투명도), Loading (스피너)

### 6.2 입력 필드

| 속성 | 값 |
|------|-----|
| 높이 | 48px (모바일 터치 최적화) |
| Border-radius | 12px |
| 기본 보더 | 1.5px #E8E6E1 |
| 포커스 보더 | 1.5px #FF6B9D |
| 에러 보더 | 1.5px #EF4444 |
| 배경 | White |
| 패딩 | 16px |

### 6.3 카드 (일정 카드)

| 속성 | 값 |
|------|-----|
| 배경 | White |
| Border-radius | 16px |
| 보더 | 1px #E8E6E1 |
| 패딩 | 16px |
| 호버/탭 | 배경 #FAF9F7, scale(0.98) |
| 그림자 | 0 2px 8px rgba(0,0,0,0.06) |

### 6.4 배지 & 태그

| 유형 | 스타일 | 용도 |
|------|--------|------|
| 색상 태그 | 원형 점 (12px), 일정 색상 | 캘린더 일정 구분 |
| 읽지 않음 | 파란 점 (8px) | 미읽음 알림 |
| 그룹 역할 | 라운드 필 (오너/멤버) | 그룹 멤버 역할 표시 |

### 6.5 사진 갤러리

| 속성 | 값 |
|------|-----|
| 레이아웃 | 1장: 전체 너비 / 2장: 2열 / 3장이상: 2열 그리드 + 더보기 |
| 모서리 | Border-radius 12px |
| 최대 표시 | 4장 (초과 시 "+N" 오버레이) |
| 전체보기 | 탭 시 fullscreen 캐러셀 |

### 6.6 모달 / 바텀시트

| 속성 | 값 |
|------|-----|
| 오버레이 | rgba(0,0,0,0.4) |
| 바텀시트 Border-radius | 상단 20px |
| 드래그 핸들 | 4px x 32px, Gray 300, centered |
| 최대 높이 | 90vh |

## 7. 인터랙션 & 모션

### 7.1 트랜지션 원칙

| 항목 | 값 |
|------|-----|
| Timing function | ease-out |
| Micro | 100ms |
| Fast | 200ms |
| Normal | 300ms |

### 7.2 주요 인터랙션

| 요소 | 트리거 | 효과 | 시간 |
|------|--------|------|------|
| 버튼 탭 | active | scale(0.96) | 100ms |
| 카드 탭 | active | scale(0.98) | 100ms |
| 바텀시트 열기 | click | slide-up | 300ms |
| 토스트 | trigger | slide-up from bottom | 300ms |
| 페이지 전환 | navigate | fade | 200ms |
| 이미지 로드 | load | fade-in | 300ms |

## 8. 반응형 & 접근성

### 8.1 브레이크포인트

| 이름 | 크기 | 용도 |
|------|------|------|
| Mobile | 375px (기본) | 주요 타깃 |
| Tablet | 768px | 캘린더 2열 레이아웃 |
| Desktop | 1024px+ | 캘린더 + 사이드 패널 |

### 8.2 접근성 (WCAG 2.1 AA)

| 항목 | 기준 |
|------|------|
| 포커스 상태 | 2px outline, #FF6B9D, 2px offset |
| 텍스트 대비율 | 최소 4.5:1 (AA 기준) |
| 터치 타겟 | 최소 44x44px |
| 에러 표시 | 아이콘 + 텍스트 (색상만 사용 금지) |

## 9. Tailwind CSS 커스텀 설정 예시

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          DEFAULT: '#FF6B9D',
          dark: '#E85A8A',
          light: '#FFE4EF',
        },
        secondary: {
          DEFAULT: '#4ECDC4',
          light: '#E0F7F5',
        },
        surface: '#FAF9F7',
        border: '#E8E6E1',
      },
      fontFamily: {
        sans: ['Pretendard', 'Inter', 'system-ui', 'sans-serif'],
      },
      borderRadius: {
        card: '16px',
        button: '12px',
        input: '12px',
      },
    },
  },
}
```
