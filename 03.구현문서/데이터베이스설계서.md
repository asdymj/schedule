## 1. 개요

### 1.1 문서 목적

기능명세서(#6) §3~§10에서 식별된 데이터 모델과 API스펙(#7)의 요청/응답 스키마를 근거로 서비스 전체 테이블, 관계, 제약조건, 인덱스, RLS 정책, DDL을 정의합니다. 본 문서는 Supabase 마이그레이션 SQL의 단일 출처입니다.

### 1.2 설계 원칙

| 원칙 | 내용 |
|------|------|
| Soft Delete 우선 | `deleted_at` 컬럼으로 논리 삭제 (events, media, comments, groups 등). 물리 삭제는 cron 일괄 처리 |
| RLS 필수 | 모든 사용자 데이터 테이블에 `group_id` 또는 `user_id` 기반 RLS 정책 적용 (NFR-021) |
| UUID 기본키 | `gen_random_uuid()` (pgcrypto), 식별자 표기는 `<prefix>_<uuid>` (시스템정의서 §5.1, 정보구조도 §4.2) — 클라이언트 노출용 prefix는 뷰/애플리케이션 레이어에서 처리 |
| 시간 표기 | `timestamptz` (UTC 저장, 클라이언트에서 KST 변환) |
| 익명화 | 회원 탈퇴/강퇴 시 `user_id`를 NULL로 변경하고 작성자 표시는 애플리케이션에서 "(탈퇴 사용자)"/"(퇴장 멤버)" 처리 (F-005, F-106) |
| JSONB 활용 | 캔버스 상태(`canvas_state`), 멘션 배열(`mentions`), 알림 페이로드(`payload`) 등 가변 구조 |
| 변경 이력 | `event_history`로 일정 변경 추적 (작성자 잠금 없음 정책 보완) |

### 1.3 ID 프리픽스 매핑 (애플리케이션 레이어)

| 프리픽스 | 테이블 | 비고 |
|----------|--------|------|
| `usr_` | profiles | auth.users.id와 1:1 |
| `grp_` | groups | |
| `evt_` | events | |
| `med_` | media | |
| `cmt_` | event_comments | |
| `ntf_` | notifications | |
| `ord_` | orders | 결제 |
| `dev_` | user_sessions | |
| `job_` | export_jobs | |

## 3. 테이블 정의

### 3.1 profiles (회원/인증 — F-001~F-005)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | uuid | PK, FK → auth.users.id | Supabase Auth 사용자와 1:1 |
| nickname | text | NOT NULL, 2~20자 | 동명 허용 |
| avatar_url | text | NULL | 200x200 리사이즈본 |
| bio | text | NULL, ≤100자 | 자기소개 |
| email | text | NOT NULL | auth.users와 동기화 |
| plan | text | NOT NULL DEFAULT 'free' | `free`\|`pro`\|`family` |
| created_at | timestamptz | NOT NULL DEFAULT now() | |
| deleted_at | timestamptz | NULL | 탈퇴 처리(F-005) — 24시간 후 영구 삭제 cron |

**관련 기능**: F-001(소셜 로그인 시 자동 생성), F-004(프로필 수정), F-005(탈퇴 시 익명화 — 본인 작성 콘텐츠의 `user_id`는 NULL 처리, profiles 자체는 24시간 후 삭제)

### 3.2 groups / group_members / group_invites (그룹 — F-101~F-108)

**groups**

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | uuid | PK DEFAULT gen_random_uuid() | |
| name | text | NOT NULL, 1~30자 | |
| color | text | NOT NULL | 8종 프리셋 hex |
| icon | text | NOT NULL | 이모지 1개 |
| type | text | NOT NULL | `friends`\|`couple`\|`family`\|`club` |
| created_by | uuid | FK → profiles.id | |
| deleted_at | timestamptz | NULL | F-108 해체 — 30일 Soft Delete 후 cron 영구 삭제 |
| created_at | timestamptz | NOT NULL DEFAULT now() | |

**group_members** (복합 PK)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| group_id | uuid | PK, FK → groups.id ON DELETE CASCADE | |
| user_id | uuid | PK, FK → profiles.id ON DELETE CASCADE | |
| role | text | NOT NULL DEFAULT 'member' | `owner`\|`admin`\|`member` |
| joined_at | timestamptz | NOT NULL DEFAULT now() | |

**group_invites**

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | uuid | PK DEFAULT gen_random_uuid() | |
| group_id | uuid | FK → groups.id ON DELETE CASCADE | |
| created_by | uuid | FK → profiles.id | |
| token | text | UNIQUE NOT NULL | 256bit 랜덤 (NFR-023) |
| code | text | UNIQUE NOT NULL | 6자리 단축 코드 |
| max_uses | int | NOT NULL DEFAULT 1 | |
| uses | int | NOT NULL DEFAULT 0 | |
| expires_at | timestamptz | NOT NULL | 발급 + 24시간 |
| created_at | timestamptz | NOT NULL DEFAULT now() | |

**비즈니스 규칙**: Free 플랜은 본인 운영(owner) 그룹 5개 미만, 그룹원 5인 이하 — 애플리케이션 레이어에서 검증(422 `BUSINESS_RULE_VIOLATION`), 트리거로 이중 보호 가능(§6)

### 3.3 events / event_history / event_decorations (캘린더/일정·캔버스 — F-201~F-308)

**events**

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | uuid | PK DEFAULT gen_random_uuid() | |
| group_id | uuid | NOT NULL, FK → groups.id ON DELETE CASCADE | |
| author_id | uuid | FK → profiles.id ON DELETE SET NULL | 탈퇴 시 NULL (익명화) |
| title | text | NOT NULL, 1~50자 | |
| start_at | timestamptz | NOT NULL | |
| end_at | timestamptz | NULL | `end_at > start_at` CHECK |
| is_all_day | bool | NOT NULL DEFAULT false | |
| is_private | bool | NOT NULL DEFAULT false | |
| color | text | NULL | 멤버별 자동 배정 색 override |
| location | jsonb | NULL | `{name, lat, lng}` |
| memo | text | NULL, ≤500자 | |
| recurrence_rule | text | NULL | RRULE (RFC 5545, F-209) |
| search_vector | tsvector | GENERATED | `title`+`memo`+`location.name` 결합 (F-208) |
| deleted_at | timestamptz | NULL | 7일 휴지통 (F-204) |
| created_at | timestamptz | NOT NULL DEFAULT now() | |
| updated_at | timestamptz | NOT NULL DEFAULT now() | |

**CHECK 제약**: `(end_at IS NULL OR end_at > start_at)`

**event_history** (F-203 변경 이력)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | uuid | PK DEFAULT gen_random_uuid() | |
| event_id | uuid | FK → events.id ON DELETE CASCADE | |
| changed_by | uuid | FK → profiles.id ON DELETE SET NULL | |
| diff | jsonb | NOT NULL | `{field: {from, to}}` |
| changed_at | timestamptz | NOT NULL DEFAULT now() | |

**event_decorations** (F-301~F-310 캔버스, 1:1)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| event_id | uuid | PK, FK → events.id ON DELETE CASCADE | |
| canvas_state | jsonb | NOT NULL DEFAULT '{"version":1,"nodes":[]}' | 사진/지도핀/영상/스티키/스티커/링크 노드 배열 |
| version | int | NOT NULL DEFAULT 1 | Optimistic Concurrency (`base_version` 비교, API §6.2) |
| updated_by | uuid | FK → profiles.id ON DELETE SET NULL | |
| updated_at | timestamptz | NOT NULL DEFAULT now() | |

> 데코 요소(`type: photo|map_pin|video|sticky_note|sticker|link|template`)는 `canvas_state.nodes[]` JSONB 내부에 저장하며 별도 테이블로 정규화하지 않음 — 캔버스 자유 배치·30초 자동 저장(F-308) 특성상 직렬화 단위 저장이 효율적(읽기/쓰기 원자성, 버전 관리 단순화)

### 3.4 event_comments / event_reactions (리액션/댓글 — F-401~F-405)

**event_comments**

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|

| content | text | NOT NULL, 1~500자 | |
| media_id | uuid | FK → media.id ON DELETE SET NULL | 첨부 이미지 1장 |

| is_edited | bool | NOT NULL DEFAULT false | |
| deleted_at | timestamptz | NULL | Soft Delete |
| created_at | timestamptz | NOT NULL DEFAULT now() | |

**event_reactions** (복합 PK — UPSERT 대상)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| event_id | uuid | PK, FK → events.id ON DELETE CASCADE | |
| user_id | uuid | PK, FK → profiles.id ON DELETE CASCADE | |
| type | text | NOT NULL | `like|heart|congrats|laugh|touched|wow` (6종, CHECK 제약) |
| created_at | timestamptz | NOT NULL DEFAULT now() | |

> 리액션 취소(`type: null`)는 행 DELETE로 처리 (API §8.5)

## 5. RLS (Row Level Security) 정책

NFR-021 정합 — "모든 테이블에 그룹 소속 검증". Supabase Auth `auth.uid()` 기준.

### 5.1 정책 패턴

| 패턴 | 적용 테이블 | 규칙 |
|------|-------------|------|
| 본인 행만 | profiles, user_sessions, notifications, push_subscriptions, user_notification_settings, orders, subscriptions, user_sticker_packs | `user_id = auth.uid()` (또는 `id = auth.uid()`) |
| 그룹 멤버만 | events, event_history, event_decorations, event_comments, event_reactions, media | `group_id IN (SELECT group_id FROM group_members WHERE user_id = auth.uid())` |
| 역할 기반 쓰기 | groups(UPDATE/DELETE), group_invites(INSERT) | `EXISTS (... WHERE group_id = X AND user_id = auth.uid() AND role IN ('owner','admin'))` |
| 서비스 전용 (RLS 우회) | audit_logs, export_jobs, notification_queue, reports(쓰기 외 조회) | `service_role` 키로만 접근 (Route Handlers, NFR-022 정합) |

### 5.2 대표 정책 예시 (DDL §7 참조)

```sql
-- events: 그룹 멤버만 SELECT
create policy "events_select_group_member"
  on events for select
  using (
    group_id in (select group_id from group_members where user_id = auth.uid())
  );

-- events: 그룹 멤버만 INSERT (작성자=본인)
create policy "events_insert_group_member"
  on events for insert
  with check (
    author_id = auth.uid()
    and group_id in (select group_id from group_members where user_id = auth.uid())
  );

-- groups: owner/admin만 UPDATE
create policy "groups_update_owner_admin"
  on groups for update
  using (
    exists (
      select 1 from group_members
      where group_id = groups.id and user_id = auth.uid() and role in ('owner','admin')
    )
  );

-- profiles: 본인만 수정
create policy "profiles_update_self"
  on profiles for update
  using (id = auth.uid());
```

> 그 외 테이블(event_comments, event_reactions, media, event_decorations 등)도 동일한 "그룹 멤버 SELECT / 작성자 또는 owner·admin UPDATE·DELETE" 패턴을 따르며, 전체 정책 SQL은 마이그레이션 파일에서 테이블별로 작성합니다.

## 6. 트리거 / 함수

| 이름 | 대상 | 동작 | 관련 기능 |
|------|------|------|-----------|

### 7.1 트리거 함수 예시

```sql
create or replace function fn_events_search_vector() returns trigger as $$
begin
  new.search_vector :=
    setweight(to_tsvector('simple', coalesce(new.title, '')), 'A') ||
    setweight(to_tsvector('simple', coalesce(new.memo, '')), 'B') ||
    setweight(to_tsvector('simple', coalesce(new.location->>'name', '')), 'C');
  new.updated_at := now();
  return new;
end;
$$ language plpgsql;

create trigger trg_events_search_vector
  before insert or update on events
  for each row execute function fn_events_search_vector();

create or replace function fn_group_owner_on_create() returns trigger as $$
begin
  insert into group_members(group_id, user_id, role) values (new.id, new.created_by, 'owner');
  return new;
end;
$$ language plpgsql;

create trigger trg_group_owner_on_create
  after insert on groups
  for each row execute function fn_group_owner_on_create();
```

> 한국어 형태소 분석(`mecab-ko`/`pg_jieba`)은 `simple` 설정 대신 별도 텍스트 검색 설정으로 교체 검토 — M2 이후 검색 품질 보강 시 `to_tsvector('korean', ...)` 적용 (시스템정의서 §1.2 정합)

| 항목 | 정책 |

## 9. 데이터 보존·정리 정책 (cron 연동)

| 대상 | 보존 기간 | 처리 |
|------|-----------|------|
| events (Soft Delete) | 7일 | cron이 `deleted_at < now() - 7d` 행 + 연관 media 영구 삭제 |
| groups (해체) | 30일 | cron이 `deleted_at < now() - 30d` 그룹 + 하위 데이터 영구 삭제 |
| media (Soft Delete) | 7일 | cron이 Storage 파일 + 행 삭제, 실패 시 재시도 큐 |
| profiles (탈퇴) | 24시간 | cron이 `fn_anonymize_user()` 호출 후 행 삭제, 미디어는 30일 유예 |
| notifications | 30일 | cron이 오래된 알림 일괄 삭제 |
| audit_logs | 1년 | NFR-026 — 자동 삭제하지 않고 별도 아카이브 검토 |
| notification_queue (sent/skipped) | 7일 | cron 정리 |
