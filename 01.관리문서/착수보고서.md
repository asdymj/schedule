## 2. 프로젝트 배경 및 목적

### 2.1 배경
친구, 커플, 가족, 소모임 등 소규모 그룹이 일정을 함께 관리하고 추억을 기록하고 싶어 하는 니즈가 증가하고 있다. 기존 캘린더 앱(구글 캘린더, 네이버 캘린더)은 일정 공유는 가능하나, 사진·영상·지도·이모지 등 미디어를 다이어리처럼 꾸미는 기능이 부족하다.

### 2.2 목적
- 친구 그룹 단위로 일정을 함께 등록하고 기록할 수 있는 공유 캘린더 서비스 제공
- 지도, 사진, 텍스트, URL, 영상, 이모지를 활용해 다이어리처럼 일정을 꾸미는 경험 제공
- 팀 초대를 수락한 구성원만 접근 가능한 프라이빗 공유 환경 구현

## 3. 서비스 범위

### 3.1 포함 범위
| 구분 | 내용 |
|------|------|
| 회원 인증 | 이메일/Google/Kakao 소셜 로그인, JWT 세션 관리 |
| 그룹 관리 | 그룹 생성, 초대 링크 발송, 멤버 역할(오너/멤버) 관리 |
| 공유 캘린더 | 월간/주간/일간 뷰, 일정 등록·수정·삭제, 개인/그룹 레이어 분리 |
| 다이어리 꾸미기 | 텍스트, 사진, 영상, URL 카드, 이모지, 지도(위치) 첨부 |
| 실시간 알림 | 새 일정 등록·변경 시 그룹 멤버 앱 내 알림 |
| 미디어 저장 | Supabase Storage 활용 (사진 10MB/장, 영상 100MB/건) |

### 3.2 제외 범위
| 구분 | 사유 |
|------|------|
| 네이티브 앱 (iOS/Android) | 1차 릴리즈는 모바일 반응형 웹으로 대체 |
| 결제 기능 | 무료 서비스로 운영 (유료 전환은 차기 단계) |
| 대용량 그룹 (100명 이상) | 1차 타깃은 소규모 그룹 (2~20명) |
